- 字体原文件：https://raw.githubusercontent.com/notofonts/noto-cjk/Sans2.004/Sans/OTF/SimplifiedChinese/NotoSansCJKsc-Regular.otf
- 字体许可证：https://github.com/notofonts/noto-cjk/blob/Sans2.004/LICENSE
