# 工作包 B：游戏文本/语音国际化验收方案

日期：2026-10-30。目标 v0.10.1；本文件保留验收方案，逐项执行范围以实际验收记录为准。依据 [内容落地](game-localization-implementation-plan.zh-cn.md)。默认 demo/关闭夹具与开启夹具都要验；不能把文档示例当成可运行样例。

## 1. 固定测试资料

使用有稳定显式 frame ID 的三幕：开始 → 含条件选择 → 结尾，另有自循环、UI sequence 视频和隐藏返回路由。设置变量变化、CG、BGM/SE/voice 计数器，记录 Session/history/文件哈希。

文本集合为 zh-CN/en-US，默认 zh-CN；语音集合为 zh-CN/ja-JP，默认 ja-JP。测试语言的 FTL 可使用可辨认哨兵，标签写中文；不要求本版产出正式英文/日文翻译。每种语音用不同频率/长度的合法 WAV 夹具，并有 silent 和缺失项；真实设备用可辨认语音素材另验，合成波形不算主观语言听感。

OS 首选语言通过平台接口注入列表，不修改测试机区域/显示语言。所有偏好在隔离目录；正式宿主资源始终只有中文，伪宿主目录只供测试。

## 2. 开关与严格内容校验

| 编号 | 用例 | 预期 |
| --- | --- | --- |
| B01 | 没有 localization；存在未引用 FTL/坏 language.json | 原有单语言加载、文字/音频/存档行为不变；不读那些文件 |
| B02 | 显式 enabled=false | 同 B01；false+src 拒绝，不偷偷读取 |
| B03 | enabled 缺失/非 bool、重复根、后续章节声明、true 无 src | 带源位置拒绝；不以第一项/目录文件推断配置 |
| B04 | 开启但缺清单、错 schema、未知字段/节点、路径逃逸 | 完整候选失败，保留旧内容；KPAK 不回退散目录 |
| B05 | texts 空、默认不存在、voices 非空无默认/空却有默认 | 拒绝；合法无语音集合有效语言为 null |
| B06 | 重复/大小写重复 locale、非规范标识、und/扩展/私有附加 | 拒绝；label 不参与匹配；字节长度上限有效 |
| B07 | 消息/字体重复路径、类型错、字体缺字、语音 asset 错类型 | 保留原清单/FTL 源位置，不自动静音或调用系统字体 |
| B08 | 仅部分非默认文本 key 缺失 | 精确回到默认文本同一消息；不借第三语言；默认缺 key 则拒绝 |
| B09 | 某目录已有消息但缺术语/循环/错参/坏 FTL | 判坏内容，不以“回退成功”掩盖错误 |
| B10 | voice 缺非默认 key、显式 silent、缺默认 key | 分别默认映射/静音/拒绝；三种结果明确区分 |
| B11 | 关闭时使用 key/text-arg；正文与 key 共存 | 拒绝；不显示 key、不把非法标记当字面量 |
| B12 | 台词/人物/选项/变量标签/CG/窗口标题的 key | 所有导出位置正确；ID、变量值、路由、HEX 和 token 不改变 |
| B13 | UI text-key-bind+有界 text-arg、repeat、跨 include | 现有 setUi 可切 key/参数，绑定前向引用与原位置正常 |
| B14 | unknown key、缺参/多参、重复参数、对象/列表、数值精度边界 | 整批拒绝，不修改其他变量/页面/持久文件 |
| B15 | 历史类静态文本声明外部参数；错误标题/混合文本来源 | 拒绝，不读取当前变量去猜历史文本 |
| B16 | 所有可选目录的语法/引用/字形、预算与 DAG 膨胀 | 即使当前 locale 不选它也被验证；无无界格式化/逐帧资源创建 |

## 4. 偏好与事务故障注入

| 编号 | 触发 | 验收 |
| --- | --- | --- |
| P01 | 缺 language.json | 两个 auto，依据系统列表计算；不写文件 |
| P02 | 空/截断/旧 schema/错 story/缺字段/重复键/超 16KiB/非规范 | 保留坏字节，提示一次，以 auto/auto 计算；不 serde(default) 补齐 |
| P03 | 同批改两通道、同一通道两次 | 前者同文件一次原子写，后者拒绝；null 表示 auto |
| P04 | 与 settings/CG/配色/快捷键/退出/剧情/存读档混写 | 整批拒绝，全部文件/UI/Session/音频保持旧值 |
| P05 | 目录占位、文件锁、原子替换失败、磁盘写失败 | 旧文件和旧语言/字体/标题/音频/缓存不变，草稿可修正重试；不先删原文件 |
| P06 | 最终动态 key、翻译标题、字体或音频准备失败 | 在写偏好前失败；活动 egui 字体不能被候选提前替换 |
| P07 | 恢复默认 | 保存两个 null，重新计算 auto，不等于直接选择默认语言标签 |
| P08 | 关闭国际化后/重新开启 | 关闭不读写已存在偏好；开启后按完整验证加载；没有临时兼容解析器 |
| P09 | screen/frame/game.enter 等生命周期提交语言命令 | 明确拒绝；不能通过自动回调写偏好 |
| P10 | 热更移除请求语言/移除默认或坏 key | 前者按 M11 完整候选回退，后者拒绝；旧文件不改写 |

## 5. 呈现、语音与剧情一致性

| 编号 | 操作 | 必须观察到 |
| --- | --- | --- |
| S01 | 当前句未打完时通过安全菜单切文本 | 同一 frame/变量/history；新句完整显示，无重复 enter/exit/CG/自动档；无字素越界 |
| S02 | 两个请求变化但 effective 不变 | 不重置逐字、不重播声音；请求文件正确 |
| S03 | 只换文本，voice 正在播放 | 原 voice 继续；BGM/SE 不重启；下一帧声音无重复命令 |
| S04 | 只换语音 | 当前 Voice 恰好停止一次，不立即播放新声；下一次真实进入取新资源；BGM/SE 不变 |
| S05 | 换语言后自动播放/Ctrl/改键的按住快进/picker/捕获 | auto 停止、时钟重置、编辑/捕获取消、先松旧键；同帧不前进 |
| S06 | 活动 UI sequence/视频/转场/调试/隐藏交接/pending 截图 | 运行语言命令拒绝；播放/旧 UI/旧文件保留，无隐式结束或补计时 |
| S07 | 非默认缺语音与明确 silent | 分别默认 clip/Stop Voice；自动播放等待依实际 voice_finished 继续 |
| S08 | 屏幕文字、选项、历史、角色、变量标签、画廊、标题 | 同一有效文本语言投影；Data::build 不覆盖回默认；不按翻译字面量路由 |
| S09 | 自循环、隐藏选项伪造、条件失败/溢出 | 原事务/控制流语义不变；翻译不能新增可用选项 |
| S10 | 语言切换后截图和手动保存 | revision 更新；未有匹配新画面时不配旧截图；语言设置本身不产生新剧情档 |
| S11 | 200 槽末页与自动十槽 | 只扫描原有当前页；当前语言生成 preview/excerpt，无 ID；截图保留保存时像素，不重编码 |
| S12 | 读旧玩家槽，当前语言与保存时不同 | save 9 验证正常，使用当前偏好；语言文件不回滚，history/变量一致 |
| S13 | active 隐藏槽跨进程恢复 | 先选语言，再恢复 key/参数 UI，视频从零；不重放幕事件、不写回偏好 |
| S14 | read.json/CG/手动与自动槽/隐藏槽哈希 | 除既有真正剧情动作外不变化；已读按 frame 共享，不生成语言后缀 ID |

音频纯计划测试不依赖设备，断言 Voice/BGM/SE 命令次数和资源 ID；设备流另记录可用/失败静音；主观听感需真人实际听到不同语言且时序正确。不能用不同正弦波的解码成功宣称日语听感验收。

## 6. 热更、容器和发布

真实文件保存/重命名/删除恢复：改当前及未选语言 FTL、清单、字体和 voice；好候选完整替换、坏编辑保留旧状态；旧 generation 候选被拒绝，不能按系统改变了语言就接受过期候选。观察兼容译文热更无幕/页面生命周期重播、无 BGM/SE/Voice 重启。

在不同系统请求列表和不同 language.json 下分别打 KPAK 1/2，确认同一源依赖集合/包内语言资源相同，均包含所有声明语言。关闭时未引用 FTL 不入包。具名 UUID 重写/跨章/合并 UI include 保留 key、开关和参数节点，源文件指纹不变；翻译资源源变化/坏内容不覆盖旧输出。

对 language.json 及大小写变体测试默认收集、显式 include、监控和发布复制排除。不得为排除偏好而把游戏 localization XML/FTL 也排除。两个真实 CLI 包完整 --check，并从源码外只带 exe/包/固定 Core/许可运行；改 cwd、删除散目录，仍能选全部语言。默认文本和语音资源缺失必须失败，不能回源码或网络找。

## 7. 实际 GUI 与跨进程清单

每项填实际 OS/后端/DPI/命令/路径/结果/未验原因，不只贴设置页截图：

1. 默认关闭的现有 demo 首次菜单、明确起始幕/读档、中文/16:9/菜单暂停/推进行为不变。
2. 开启夹具的两个独立选择区、跟随系统、应用/取消/恢复默认、没有语音集合的界面；游戏菜单及其他局部页面全程同语言，无未知 key。
3. 安全菜单换文本前后，长短句换行、中文/拉丁字形、标题、选项、历史和槽位当前页；D3D11 与 CPU 像素模式分别观察。
4. 字体/文本失败、写文件失败用隔离夹具触发，旧字体/画面/音频/标签不部分改变；错误提示仍是宿主中文。
5. 声音正在播放时换文本与换 voice 的差别；自然结束、静音、下一幕选择，分别记录计划/设备/听感。
6. 保存手动槽 200/自动槽后完全退出，以同语言文件重启，再改文本/语音选择后加载：frame、变量、条件选项、历史和语言偏好分别核对。
7. UI sequence 与隐藏 active 交接期间正常退出，再重启恢复，声音/视频仍按既有生命周期，UI key 按当前语言投影。
8. 100/150/200% DPI 的输入命中、中文/长标签/换行、选择列表；大目录 60 秒操作下格式化/缓存/PCM/字体内存不持续增长，不逐帧读文件。

RTL、未支持塑形、语音流式大包和视频多音轨只验证明确限制，不列为已实现。真实 OS 语言探测至少在一台 Windows 验证结果与可见用户首选顺序一致，其他平台未实现时明确报告默认降级，不把 Windows 通过当作跨平台通过。
