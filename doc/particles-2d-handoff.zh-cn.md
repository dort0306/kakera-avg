# 2D 粒子效果交接（待实现）

日期：2026-10-31。当前已实现版本为 v0.11.2；本功能归属根目录 [PLAN.md](../PLAN.md) 中的 v0.11.3 待实现规划，技术方案见 [v0.11.3 待实现计划](v0.11.3-implementation-plan.zh-cn.md)。本轮只加入待实现清单，不新增 XML 语法、JS 命令或渲染代码。以下为实施建议，正式接口与具体硬预算须在实现前写入策略并验证。

## 1. XML/JS 优先评估

现有 image/panel、ctx.animate、ui-media fade 和组合标签可拼接少量固定图片动画，适合简单装饰；组件只在加载期展开，JS 无 tick、时钟和随机能力，不能据此提供有界持续发射、逐粒子运动与回收。应复用已有 XML 布局、图片资源、页面和生命周期，最小扩展宿主粒子配置校验、呈现更新与绘制能力，不增加 ECS、异步 runtime、任意 shader、脚本定时器或常驻 JS 回调。

## 2. 首期范围建议

- 采用 2D 图片粒子，提供雨、雪、花瓣、光点演示；纹理引用已声明图片资源 ID，经 ContentSource 预载并共享缓存。
- XML 声明发射区域、位置/层级/裁剪、最大发射数、速率、生命周期、初始速度及变化范围、加速度、大小、旋转、颜色与透明度变化；首期优先普通 alpha 混合，不承诺碰撞、物理流体、3D 或自定义 GPU 模拟。
- JS 只收集明确的开始/停止/清空候选命令，控制已声明发射器 ID；具体名称待定，不向作者开放路径、原生对象或逐粒子写入。
- 明确有限 burst 与持续发射的停止语义：停止发射后存活粒子可自然结束，清空则立即移除；同 ID 重复触发的替换/重启行为需在正式接口中唯一规定，避免隐式叠加无限实例。
- 剧情层效果与 UI 装饰层分别定义时钟归属：剧情层受菜单暂停，UI 层可沿用现有 UI 演出时钟；两者均在失焦、提示和调试暂停时冻结且不补积累时间。页面关闭、场景切换时按声明归属清理，不能泄漏到下一页/幕。

## 3. 架构、事务与预算

Model 只保存静态配置（如确需剧情层配置），粒子实例、随机状态、时钟和 GPU 资源由 App 呈现层持有，不进入 Session/剧情槽。绘制只读取已准备的粒子几何及纹理；更新不推进剧情、不执行脚本、不做资源 IO/解码。随机仅在宿主呈现层使用，不开放给 QuickJS 条件或更新逻辑；测试可注入固定种子，不影响剧情重放结果。

所有参数须校验有限性、范围、ID/资源类型及组合预算。声明数量、同时活动发射器、单发射器与全局存活粒子、每次更新新增粒子、寿命、几何内存与纹理复用均设硬上限；长帧或恢复时限制积分步数和补发量，不能用速率乘巨大 dt 一次分配海量实例。具体数值先在实现计划确定，再以压力用例验证，不扩大现有图片/滤镜预算。

整批候选完成目标、资源和预算准备后才能一次提交；坏配置、脚本异常、预算超限或资源失败保留旧 UI/Session/音频/效果。新命令沿用现有命令数、生命周期派发及单意图约束；不借粒子控制开放剧情跳转或持久 IO。

GPU 走现有原生纹理与 2D 几何管线，CPU fallback 保留可用绘制路径，不引入正常帧 readback。GPU 设备重建清理失效句柄，按声明重新准备，不能把旧设备资源带入下一帧。目录与 KPAK 1/2 使用同一资源引用与严格加载；坏热更保留旧状态，成功热更清理旧实例并重建声明状态，不重放剧情事件。

## 4. 恢复与数据契约

粒子是瞬时呈现，不保存单粒子进度或随机状态。读档/重开/隐藏交接恢复时，以当前页面/场景的声明初态重建；不重播历史事件的 burst。自动发射与显式触发必须区分，避免读档重放生命周期造成双重发射。

复用 story 8/UI 3 的扩展语法是否足够，需在正式 XML 设计时明确；本次规划不改变任何 schema 或 demo content-version。若实现会改变剧情内容兼容性，再单独说明并提升 content-version，不因应用版本变化自动升级存档。当前 API 手册不得将拟议粒子语法列为已支持。
