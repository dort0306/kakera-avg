# v0.8.3 调试 API 与发布文件清单策略

日期：2026-10-27，先于本版功能代码。保留当前工作区的 v0.8.2/标题改动，版本升为 0.8.3；story 8/UI 3/save 8、KPAK 1/2 不变。

## 实现边界

- XML/JS 没有进程通信、运行态查询、挂起提交和发布文件选择权限，两项运行能力需要明确 Rust 宿主扩展。游戏脚本不新增网络、路径或任意调试命令。
- 工程模式显式启用调试 TCP JSON Lines v1；只绑定 loopback，必须提供独立令牌文件和隔离 save-dir，发布/--check 拒绝调试参数。远端机器通过安全隧道转发，不直接提供无 TLS 的公网调试监听。
- 支持 status、pause/resume、breakpoints、advance/choose、reveal/skip_transition。命令严格解析、有界帧/队列/超时/去重与状态修订检查；状态不暴露路径、GPU/Core/解释器对象。不是 JS 行级调试器或任意跳转/变量注入。
- 进入候选先验证条件、更新、生命周期及媒体，再命中断点；提交前保留旧 Session/音频/效果，缓存完整候选，继续才提交一次。暂停冻结呈现/自动/Ctrl/视频与音轨；调试阻止正常剧情输入，热更不替换未决候选。调试对象不进入 Model/存档。
- 打包先通过受记录的 ContentSource 收集当前引擎实际读取的 XML/JS/图像/字体/音频/视频/模型依赖；默认附带约定许可证目录。可选严格 kakera.package.json schema 1 显式 include 文件，不支持模糊通配或猜测路径。
- KPAK 1/2 的真实打包 CLI 使用上述文件集建立固定候选，复查选中文件及依赖清单后原子输出；未引用的普通文件/模型权重/编辑器元数据不自动入包。低层容器编码 API 仍可用于任意已授权数据，工程热更快照不改成资源裁剪器。
- 编辑器尚未实现；本版更新设计为可配置本地/远程 Chat Completions 兼容 AI API，模型 ID 不固定，不捆绑必需 Qwen 权重。身份凭据独立秘密存储、能力探测、远程发送范围和错误语义写入文档。
- 比较 VS Code 插件、Code-OSS 分叉与独立编辑器：结合当前可视帧需求、源码往返、调试适配、发行成本和非程序作者体验给出结论，更新全部当前手册；历史版本记录保留。
