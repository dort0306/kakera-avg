# UI 演出与角色音效落地计划

日期：2026-10-28，基于 v0.8.4；应用版本和 story 8/UI 3/save 8、KPAK 1/2 当时不变。v0.9.0 起存档升至 9，frame.video 已由 UI sequence + 生命周期交接取代，详见 [v0.9.0 落地计划](v0.9.0-implementation-plan.zh-cn.md)。

## 实现边界

v0.9.0 起该计划中“剧情过场继续使用独立视频 frame”的部分已被取代：Frame.video 删除，剧情视频也改用 UI sequence + 生命周期交接，见 [v0.9.0 落地计划](v0.9.0-implementation-plan.zh-cn.md) 与 API 第 32 节；本节以下保留 UI 演出作为独立瞬时序列的原始边界，不伪造剧情 frame，不修改变量/历史。现有 XML/JS 无 UI 视频覆盖层、通用透明度动画及受限 UI 音效能力，故扩展这些明确 Rust 边界，其他交互优先 XML/JS。

- UI 根新增 ui-media 分组，声明 sound（单个或带权候选组）与 sequence（fade/video/sound 步骤）。可跨 include 文件分组，统一校验资源/角色/页面/控件引用和预算。
- sequence 为一次性有界列表，结束可 return/open:页面/close；screen 的 sequence 属性在顶层页面真正进入时自动触发，ctx.sequence 显式触发。完成与鼠标/空格跳过共用一次性完成入口，消费输入，不穿透剧情；跳过不补播未来音效。
- fade 支持所有 UI 节点和容器，最终透明度保持；时钟独立于菜单的剧情暂停，失焦/提示/调试暂停仍冻结。场景切换/读档取消瞬时序列，热更候选延后至演出结束，设备重建取消，不入存档。首期为顺序透明度演出，保留已有图片动作；不增加任意 JS tick/定时器。
- UI video 覆盖客户区等比显示，暂停底层剧情，结束恢复原页面栈或预先验证的目标页。UI 视频与剧情视频互斥，保持至多一个解码线程。演出中禁止存档/新剧情操作，等待既有自动存档提交后才启动。
- button 可声明 sound，JS 可 ctx.playSound。普通单资源和音效组都经过作者禁用、玩家排除资产/禁用角色、总开关过滤；空集合静音，宿主用无偏随机数在剩余权重中选取，不影响剧情重放。角色资产归属必须一致，禁止直接资源播放绕过角色过滤。
- ui-audio.json schema 1/story_id 独立保存总开关/禁用角色/排除资源，原子替换，坏配置提示并用默认值；JS 仅能修改声明的 ID。UI 绑定 audio.enabled/audio.actor.ID/audio.excluded.ID 可展示偏好，不随读档回退，文件排除出监控和发布。
- UI 音效独立有界通道，遵循 muted/se_volume/失焦，不被菜单暂停；角色关闭或单条排除立即停止对应在播 UI 音效，不影响剧情配音/BGM。所有资源预载/解码预算沿用，绘制只读。
- 首期上限：64 sound 组，每组 64 候选，64 sequence/每组 64 步，fade 1–10000ms/透明度 0–1；单演出不超过 10 分钟，视频沿用既有预算；UI 声音最多 4 路。

## 验证

严格解析、跨文件前向引用/源位置、静态及运行期预算；随机前过滤/权重边界/全部排除静音/角色与单资源一致/坏偏好/原子失败；淡入淡出最终态、菜单/失焦时钟、自动触发/取消、跳过只完成一次且不补声音；UI 视频与剧情互斥、完成/跳过返回/失败保留剧情；完整检查及两格式发布重载。demo 提供演出页及角色音效开关，API/README/指南/AGENTS/验收同步。GUI、音频设备流与听感分别记录，不能由纯测试替代。
