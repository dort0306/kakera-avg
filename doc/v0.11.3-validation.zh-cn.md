## 4. 实际 GUI 检查（Windows 桌面窗口，D3D11 原生后端）

以 `target/debug/kakera-avg.exe --project games/demo --save-dir temp-test/gui-saves` 启动真实窗口并手动点击：

- 标题页 → HUD → “效果演示” → “粒子”可正常进入；“粒子”按钮排在“组合 / 分页”和“暂停预览”之间，未与原按钮重叠。
- 粒子页四块区域分别渲染雨（纵向流线）、雪（圆形光点）、花瓣（粉色椭圆）、光点（金色四角星）；两块连续截图之间位置不同，确认在持续运动；页面为模态菜单（剧情暂停）时粒子仍在播放，符合“菜单不冻结 UI 演出”的约定。
- 粒子被各自矩形裁剪，绘制在面板之上，层级与 16:9 舞台一致；中文标题与提示无遮挡。
- 点击“清空”后所有粒子立即消失，且不会因为普通 UI 提交重新自动发射；点击“开始发射”后雨/雪/花瓣恢复；点击“星火爆发”后光点区域出现金色星火。截图见 [粒子页](screenshots/v0.11.3/particles.png)。
- 设置页：新增“总音量”滑条位于自动播放等待与背景音乐之间，面板底部不再溢出；把滑条拖到约 0.495 后，其余四项分项值保持不变，`settings.json` 写入 `"master_volume": 0.495`；完全退出进程再重新启动，设置页显示 0.495，确认跨进程保存。截图见 [设置页](screenshots/v0.11.3/settings-master-volume.png)。
- 关闭窗口后进程退出，退出补写完成。

一次截图未捕捉到星火（寿命 0.7–1.4 秒，截图往返延迟超过该窗口），随后用连续点击在同一时刻产生多批 burst 才捕捉到；这属于验证手法限制，不是功能缺失。生成路径另有自动化用例覆盖。
