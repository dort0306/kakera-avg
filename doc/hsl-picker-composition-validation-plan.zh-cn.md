# HSL 选色器职责拆分验收方案

日期：2026-10-30。状态：**必测核心项已执行**（2026-10-30；实际记录见本文第 7 节，未执行项明确列出）。配套 [落地方案](hsl-picker-composition-implementation-plan.zh-cn.md)。旧记录中的通过数量不复用为本方案结论；本节以下保留最初的预期矩阵，实际结果只写在新增的第 7 节。

## 1. 验收对象与准备

只验收控件仅含色相环、方形和可选 alpha，以及作者独立展示仍可自由组合。RGBA 事件/偏好和 HSL 数学保持原契约。使用独立测试工程和 save-dir，不污染作者存档。

先记录源码状态（包括未提交改动）、实际 EXE 绝对路径及 SHA-256/构建时间、启动参数、工程路径、存档路径、后端和 DPI。编辑器内置 EXE 与 target/debug EXE 分别识别，不能只因文件同名就认定版本一致。若反馈来自编辑器，优先用同一个测试工程比较已确认构建的独立播放器和用户实际使用的副本；未覆盖后者时明确报告。

准备四种 author UI 组合：仅 picker、picker+外部预览、picker+外部 HEX、三者同时。所有外部展示均可移到控件左右/上方/另一页面或完全移除；接受候选的回调只更新同一个绑定 UI string。另准备故意拒绝/修正候选的回调，防止把合法回退当故障。

## 2. 自动布局与严格解析

| 编号 | 输入或操作 | 必须结果 |
| --- | --- | --- |
| L01 | alpha=false，128×128 / 256×256 | 加载成功，D 分别为 128/256，无透明度行、间隙占位和额外焦点 |
| L02 | alpha=true 或省略，128×154 / 256×282 | 加载成功，D 分别为 128/256，alpha 行高 18、距色盘框 8 |
| L03 | 无 alpha 的 W 或 H 小于 128；有 alpha 的 W<128 或 H<154 | 拒绝并保留 XML 文件及位置；128×128 省略 alpha 必须拒绝 |
| L04 | 256×320、400×282、128×400、浮点尺寸 | 按 D=min(W,H−R) 居中；环不拉伸，方形保持正方，alpha 宽 W−16；不恢复旧 96 高度 |
| L05 | 非法/缺失 value、错误变量类型、重复 ID、repeat、未知 show-preview/show-hex 等属性、超过八控件 | 按当前严格契约拒绝；不意外接受新属性或丢失诊断 |
| L06 | 0.5/1/1.5/2 舞台缩放、父 panel 位移/裁剪 | 所有内容与命中统一缩放和偏移；不重复乘 DPI；绘制不越外矩形/父裁剪 |

优先复用现有几何/解析测试，无需建立新布局框架。明确断言环和方形尺寸、alpha 的存在与边界、内容组居中，不能只断言“没有崩溃”。

## 3. 绘制职责与组合

- 无 alpha 的最小夹具只渲染环/方形/选择标记/焦点反馈；有 alpha 时仅额外出现条内棋盘、渐变和滑块。不存在独立预览矩形和 HEX 文本，不留下旧 preview/hex 几何或布局保留常数。
- 针对最小夹具检查该控件贡献的绘制图元/文本任务，断言没有 HEX 文本图元及独立预览区域。不可只扫描整页是否出现颜色字符串：外部 label 本就允许显示它。
- 没有内置文本的帧仍应产生正确 #RRGGBBAA 事件。使用六位/小写合法输入时遵循现行接受规则，事件输出仍规范大写九字符；alpha=0 的 RGB 不丢失。
- 外部 panel 的 color-bind、label.bind 均读取同一个已提交 UI string。它们可独立存在、隐藏或删除；picker 不依赖其节点 ID、位置、字体或是否在同页。
- 删除内置预览不应删掉 alpha 棋盘；alpha=false 则条、条棋盘及其焦点/命中均不存在。
- 作者需要棋盘预览时，既有 XML 图像/面板可组合工作，检查输出不新增 IO/纹理重建或预览专用宿主命令。

## 4. 指针、键盘与回跳回归

| 编号 | 场景 | 必须结果 |
| --- | --- | --- |
| I01 | 方形含四角/各边的 5×5 点阵，拖动到不同内部终点 | S/L 与坐标对应；标记能自由移动，释放后位置保持；黑白边缘横向移动虽 RGBA 可相同也不跳角 |
| I02 | 按下、移动、释放分帧；同帧按下/释放；仅释放帧才到达新终点 | 最终位置被处理，同位置不重复事件，一帧至多一个业务事件 |
| I03 | 方形拖出到环/控件外，再返回/释放 | 手势子区锁定，S/L 按轴夹取，不转为调 H，不触发外部预览或剧情 |
| I04 | 新布局的确定间隙/留白按下；点击控件外的作者预览和 HEX | 前者不改色、不开始抓取且阻挡剧情；后者遵循外部节点原有交互，不被旧 picker 命中区吞掉 |
| I05 | alpha=false 的矩形底部、原旧 alpha/预览/HEX 行附近 | 根据新实际布局判断，不存在幽灵滑块/预览；坐标处若已成为环/方形则应正常编辑，不能盲用旧坐标断言无事件 |
| I06 | Tab/Shift+Tab、方向键、Escape；alpha=false 的 Tab 顺序 | 仅环/方形/可选 alpha，仍可离开控件；调整 H/S/L/A 正确，旧 HEX/预览不成为焦点 |
| I07 | 禁用、父隐藏、裁剪、底层页、提示/失焦/调试、热更/读档/语言切换 | 沿用原输入阻挡/清理与释放屏障；无旧抓取、陈旧候选或剧情按键穿透 |

### 必须独立执行的“松开回跳”门槛

1. 用最小“接受候选”夹具，从与初值明显不同的位置拖动、松开。记录释放候选、JS 收到的 ctx.value、事务提交后的 UI string，以及下一帧读取的绑定值。必要的观测限于测试/诊断，不能把逐帧 JS 或生产刷屏日志作为修复。
2. 连续至少十个空闲 UI 帧并观察实际窗口至少两秒。绑定 string、控件标记、外部预览和外部 HEX 保持一致；之后从该点继续键盘或鼠标编辑，不能重新从初值起算。
3. 分别覆盖色环、方形、alpha；alpha=false/true；普通内部点、灰阶轴、黑白边缘和透明 RGB；两控件互不串缓存。
4. 拒绝候选时原绑定/外部展示保持，控件遵循原回退和抓取终止契约；修正候选时所有节点显示修正后的提交值，不能坚持显示原候选。
5. 自动回归必须包含真实 App → on.ui → host 候选验证/提交 → 下一帧 Data/渲染链路。手工向 render 测试快照写回事件值可作为几何单测，不能单独证明 App 回跳已解决。

任何“正常接受后仍回跳”、绑定与标记不一致、事件未派发或被错误覆盖，都阻止验收通过。分清脚本主动重置/拒绝与宿主缺陷，不能仅从最终画面猜原因；也不得把回跳归因给作者而不验证接受回调。

## 5. 实际窗口验收

必须使用可识别构建的播放器，在 D3D11 正常后端与 CPU fallback 分别检查，并记录实际 DPI；100%/150%/200% 逐项记录，未执行的列为未验，不能笼统宣称全 DPI 通过。

1. 检查紧凑的两种控件、256×320 非紧凑矩形、中文和 16:9 页面。控件内部没有独立色块预览、HEX 或旧固定空行；外部预览/HEX 只在作者声明位置出现。
2. 自由拖动方形四角/边缘/内部，拖出再返回；拖环和 alpha；每次松开后等待，核对外部显示及后续编辑起点。观察连续过程，不能只凭调用 drag 后的单张截图宣称未回跳。
3. 同页并列 alpha=true/false，外部预览或 HEX 分别隐藏/移位/移除；不影响选色和其他节点。Tab 循环、焦点转移、菜单/提示/失焦恢复按原契约工作。
4. demo 草稿预览、取消后重开、应用和恢复默认；独立测试目录应用后完全退出再启动，颜色/透明度正确恢复。只持久化 RGBA 偏好，不恢复瞬时指针、浮点缓存或焦点。
5. 在带剧情的页面检查点击间隙不触发前进/快进/自动播放，离开控件后释放旧按键并重新按下才触发剧情。外部只读 label 不能被赋予隐式剧情/选色事件。

本变更不修改音频或媒体能力，无需把声音设备与听感捆绑为完成条件；若未测试，报告“未涉及/未复验”，不沿用历史媒体验收。
