# 工作包 C：三角 HSV 与配色验收方案

版本归属：**v0.10.0**（2026-10-30 定稿）。本文是验收任务清单，不是逐项通过记录；实际执行结果、修复复验及仍未完成的环境矩阵见 [验收记录](ui-extensibility-validation.zh-cn.md) 与 [独立复验](ui-extensibility-independent-review.zh-cn.md)，不得因版本定稿将未验项目改记通过。

## 1. 纯颜色与几何

| 编号 | 场景 | 必须断言 |
| --- | --- | --- |
| C01 | HEX 格式 | 六位/八位、合法大小写输入规范化；空值、错长度/字符、名称/路径、非字符串拒绝；输出固定大写九字符 |
| C02 | 色相边界 | H=0/60/120/180/240/300 得红/黄/绿/青/蓝/品红；360 归零；全通道在界内 |
| C03 | 三角顶点 | H=(S=1,V=1)，W=(S=0,V=1)，B=(V=0)，所有顶点/边与标记可相互映射 |
| C04 | 内部采样 | 权重(H,W,B)=(0.25,0.25,0.5)、H=红时应得 #804040FF；防止误用线性 HSV/双 gamma |
| C05 | 重心往返 | 内部网格、边/角和近退化位置往返误差受限；最近边/顶点投影真的是欧氏最近点 |
| C06 | 灰色/黑色 | 改灰色 H 不发重复业务值，但提高 S 后保留新 H；V=0 的 S/H 稳定，首次初始化有明确定义 |
| C07 | Alpha | 透明非零 RGB 往返不丢失（如 #FF000000）；alpha=false 保留原 A；alpha 条 0/1 与中值正确 |
| C08 | 数值健壮性 | NaN/无穷/零尺寸/超界非法候选拒绝；纯几何无除零，不能默认为黑色掩盖错误 |
| C09 | 量化 | sRGB 字节↔HSV 随机/边界样例，往返每通道至多一字节；不混淆 HSL、预乘或线性颜色 |

数学参考值由明确公式/独立计算得到，不把实现函数自身调用一遍当预期。固定种子测试若使用随机，只在测试端，不向游戏 QuickJS 开放随机。

## 2. XML/绑定/装配

- 合法 color-picker、alpha 默认/false、ui string 前向引用；value/event 缺失、非 string、只读 colors/game/vars、repeat 内、子节点、未知属性和过小尺寸均按源文件/行列拒绝。
- palette 槽位 ID/数量/初值、重复/大小写策略、跨 include 前向引用与重复诊断；未知根组/字段不因新增节点而放宽。
- color 与 color-bind 互斥；ui string/已声明 colors 绑定成功，其他表达式和非法颜色即使节点隐藏也拒绝。
- 外部 setUi/打开页/恢复/热更只更新标记，不自动回发 changed 事件。变色和另一无效命令同批时，Session/UI/偏好均不部分提交。
- nine-patch 全部分段 tint、图片共享纹理、label 中文/逐字 job 颜色、button 仅背景/tint 等语义与方案一致；不能把按钮默认白字也误染成背景色。
- UI include 合并和原位置诊断、源指纹复查、两格式包独立重载都包含 palette 与新节点；源工程不改写。

## 3. 输入与手势

| 编号 | 场景 | 必须断言 |
| --- | --- | --- |
| C20 | 环/三角/alpha | 按下命中正确子区，拖出仍锁定子区；不跨区跳值，释放结束抓取 |
| C21 | 阻挡 | 控件内拖拽/禁用区域/底层页不向背景发事件；窗口黑边/隐藏/遮挡不能开始编辑 |
| C22 | DPI/裁剪 | 舞台比例、不同 DPI 和部分裁剪时坐标一致；标记不会跟鼠标偏移一个标题栏/缩放倍率 |
| C23 | 单次提交 | 同帧多个 move 合并，最多一次 JS；点击其他按钮与拖拽不会同帧写两次；无输入不反复回调 |
| C24 | 业务失败 | JS 抛错/返回非法颜色/批次其他错误后，旧值保留，标记回退，抓取结束且错误不每帧刷屏 |
| C25 | 陈旧候选 | 换页/关闭/失焦/热更/读档/重开/绑定改动后旧指针事件丢弃；相同 ID 的新页面不能继承旧抓取 |
| C26 | 独立缓存 | 两个控件的 lastHue/焦点不串用，灰色重开/销毁遵守重置规则 |
| C27 | 键盘调色 | 子区焦点、H/S/V/A 步长和 Shift 粗调、边界夹取正确；Escape 结束编辑但不伪装整页取消 |
| C28 | 与 B 联动 | 前进/快进设成方向键/Shift/同键时，调色焦点拥有输入，不推进剧情/跳视频；快捷键捕获优先且取消现有抓取 |

重复点击同色不产生无意义 IO。绘制可维护局部交互提案，但不得直接修改 UI 变量或调用 JS；用测试计数证明事件只经 App 提交边界执行。

## 4. 玩家配色与持久化

1. 打开设置从当前 colors 复制草稿，连续调色只改预览，正式 HUD 和文件不变；取消后丢弃草稿效果，再打开使用已提交值。
2. “应用”可一次修改多个不同槽位，完整 UI/颜色校验与原子写成功后一起生效；重复同槽、未知槽、非法色或超出命令预算整批拒绝。
3. ui-colors.json 必需顶层字段/正确 schema/story、稀疏 overrides、未知/重复键、非规范值、16KiB 与截断严格测试。新槽位没有覆盖时按格式使用作者默认，不是旧字段迁移。
4. 缺文件默认；坏文件保留并只提示一次。锁文件/目标目录/临时写失败/原子替换失败时，旧文件与正式颜色不变，草稿可重试。
5. 单槽 null 恢复默认、全局恢复默认写空覆盖；均不先删文件。不同故事/存档目录隔离，普通槽/自动槽/重开/隐藏恢复不会撤销已提交覆盖。
6. 试图与 settings、快捷键、CG、剧情、普通存读档或退出混写时拒绝；生命周期/active 交接写偏好拒绝。普通预览不被误当成持久写操作。
7. 热更坏绑定/非法声明保持旧内容/颜色；删除已被覆盖槽位报告不兼容；不能悄悄删除玩家文件或把旧覆盖套到同名新业务。
8. ui-colors.json 及大小写变体不触发工程重载，不进 KPAK 1/2，显式附加清单不能绕过；发布目录无测试偏好。

## 5. 绘制、性能与实际像素

- 证明画面确为环内三角形，鼠标三角外角落不会按矩形 SV 取色；检查六个色相边界、顶点和内部采样，选中值与显示一致。
- 检查 sRGB 中间亮度和透明叠加参考图。纯色/灰度/半透明/全透明都要看，不能只看红绿蓝三个角。像素误差阈值在最终记录中写明，AA 边缘与内部采样分开。
- 连续拖动至少 60 秒：无每帧图片解码/纹理上传/读回，mesh 顶点/三角数量不超方案预算、JS 最多一次/更新、无持续增长的缓存。DPI/改尺寸最多重建有界几何，不开解码线程。
- 若做 GPU readback，只作测试；常规选择过程不能依赖它。CPU 像素窗口仍可走 D3D11 UI 通路，不能将这项验收称为软件光栅器已完成。

## 6. 实际 GUI 和跨进程

用隔离目录分别测试 D3D11 和 CPU 工程窗口，以及两种真实发布包：

1. 中文设置页展示颜色控件、HEX、透明预览和应用/取消，1280×720 逻辑舞台正常；至少验证 100%/150%/200% DPI 和一个实际窗口缩放场景，未测必须列出。
2. 选红色→降低饱和度为灰→改变 H→恢复 S，确认没有跳回红；选择黑色再恢复，alpha 从 0 到 1，检查标记和颜色数值。
3. 调整对话面板背景与文字，预览不影响正式 HUD；取消/应用各一次。应用后返回剧情，中文换行/逐字颜色和 alpha 合成正确。
4. 完全退出再重启，配色恢复；随后加载以前的手动/自动槽、进入隐藏交接，确认不会回滚已保存配色。控制指针/HSV 缓存不恢复。
5. 打开别的模态页、失焦、修改 UI 热更、按快捷键捕获，确认拖拽取消且输入不穿透。绑定到同键的快进/前进不误触发。
6. GUI 注入一次坏偏好/保存失败，保留旧值且可重试；测试结束关闭测试窗口，不修改玩家目录。
