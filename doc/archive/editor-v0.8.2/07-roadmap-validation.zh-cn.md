# 07 实施路线与验收

状态：计划，非完成报告。编辑器建议使用独立产品里程碑 E0–E5；不在本次规划中擅自提升播放器版本或实现代码。

## 1. 阶段与交付

| 阶段 | 主要工作 | 出口条件 | 依赖/估算 |
| --- | --- | --- | --- |
| E0 技术证实 | 锁定引擎；导入 demo；XML/JS 来源往返原型；Qwen3.8-27B 原生图文/结构输出/内存测试；测试发行工具清单 | 一套可复现模型组合和模型质量/性能报告，原始源码无损保留；没有假装可视解析复杂 JS | 1–2 人周，任何模型原生路径失败先调整 AI 范围 |
| E1 手动编辑 MVP | 项目/资源库、帧卡/完整舞台属性、显式稳定 ID、受管路由/变量、撤销/恢复、校验和外部试玩 | 无代码作者手工完成分支 demo，XML/JS 可独立运行；模型未安装仍可创作 | E0；2–3 人周 |
| E2 导入与往返 | 多章节/源位置、Opaque 逻辑、外部编辑冲突、图集/点九/模型依赖、纯游戏导出 | 原项目导入后不改的代码逐字保留；模型/索引不泄漏到内容根 | E1；2–3 人周 |
| E3 AI 辅助创作 | 本地模型管理、缓存描述、拆幕、候选排序、结构化提案和作者审阅、取消/过期检测 | 指定模型完成中文剧情到可运行 XML/JS 的可撤销流程，质量指标达标 | E0 模型通过 + E2；2–3 人周 |
| E4 帧级调试 | 工程专用宿主协议、断点/时钟暂停、运行态快照、路线重放、候选替换和源映射 | 提交前断点不改变旧 Session；正常继续/保存约束不被绕过 | E2 稳定；2–3 人周，可与 E3 部分并行但非无限并行承诺 |
| E5 发布闭环 | 工具版本锁定、KPAK 1/2、发行清单、源码外测试、离线安装与文档 | 无源码/SDK/模型服务的机器可运行游戏；发行物不含作者私有数据 | E3/E4；1–2 人周 |

总量粗估 10–16 人周，按一名熟悉本项目的全职开发者加作者/QA 持续参与估算，不是交付日期承诺；不含美术制作、模型训练、通用 JS 行级调试器或新的播放器渲染能力。模型后端故障、任意手写源码往返和 GPU 互操作是主要不确定项，E0 需重新估算。

E1 可以作为首个无 AI 可用版本；完成用户要求的“内置 Qwen3.8-27B 自动整理 + 方便调试/打包”的产品闭环至少要到 E3/E5，不能以手动 MVP 冒充全部完成。

## 4. AI 验收目标

以下是建议产品门槛，必须 E0 与作者确认并用冻结样本评估，**不是本次实测结果或厂商保证**。

- 准备至少 100 个带来源段落的中文幕、200 个已标注背景/立绘/表情样本，以及至少 20 个明确无匹配案例；开发集与留出验收集分开。
- 最终接受提案中未知资源 ID、类型不匹配、越界路径和非法属性为 0；失败提案必须被拦截，而非计算进“生成成功”。
- 作者声明保留的原台词必须逐字保真（除明确批准的换行规范化）；AI 擅自改台词为失败。
- 候选 Top-3 覆盖目标可先设为 ≥90%，无匹配案例正确标注目标 ≥90%；Top-1、人工修订数和平均人工耗时必须同时报告，不能只报结构 JSON 合格率。
- 对模型正确率不作随机概率包装；提案结构验证通过率、自动修复次数、最终可执行路线覆盖率分别统计。
- 结构语法保证不等于语义正确：即使 JSON 全通过，也必须有候选资源、逻辑及人工审阅记录。
- 目标硬件记录精确 GPU/驱动/VRAM/RAM、量化/视觉组件/上下文/图片数、首 token/总耗时、峰值占用、取消回收和与播放器同时运行结果。交互任务目标可暂定中位数 ≤60 秒、取消后 5 秒内 UI 恢复可用，实际阈值需测量修订。
- 验证服务未安装、权重损坏、显存不足、图像能力缺失、截断 JSON、无限重复、协议不支持、服务崩溃、取消/重试/过期和素材提示注入。失败不能修改源码。

## 5. 调试与发布验收

断点条件在隔离只读环境求值；停在提交前时旧位置/变量/历史/音频不变。继续只提交一次，目标校验失败发出 rejected。菜单、失焦、断点、视频结束事件和自动保存等待组合不丢事件、不积累暂停时间。

独立验证补全/推进仲裁、隐藏选择、分支、自循环、历史检查点、200 手动槽/10 自动槽与跨进程恢复。调试场景预览不能产生正式槽位；所有运行快照与源 generation 一致。

GUI 检查编辑器中文、缩略图、舞台缩放/高 DPI、图集区域选择、点九内容边距、视频/模型；真实播放器检查 16:9、标题、菜单暂停、持久化与媒体。音频设备流和主观听感分别记录；锁屏时暂停 UI 验收。

KPAK 1/2 均做完整校验；KPAK 2 大文件回归包括超过 512MiB 的实际包，不能仅依赖当前小 demo。源码外发行目录在没有工程、SDK、模型服务/权重和开发者字体的环境运行；完整 --check、真实媒体、许可及泄漏扫描都通过后才算交付完成。

## 6. 风险与停止条件

| 风险 | 降低方式 | 需要停止/缩小声明的条件 |
| --- | --- | --- |
| 指定模型/量化在目标 GPU 不稳定 | E0 实机锁定完整组合，保留手动编辑 | 不宣称该平台支持内置看图关联 |
| 任意 JS 往返不可判定 | Managed/Recognized/Opaque 分级 | 不做破坏性自动接管 |
| 资源标签误关联 | 人工标签优先、候选/缺图、作者审阅 | 不自动接受未知角色/表情 |
| AI 与渲染抢显存 | 有界任务、暂停推理、降低上下文/缩略图 | 不以播放器崩溃换取 AI 成功 |
| 多文件提交中断 | 日志与完整代次快照 | 未恢复一致状态不继续构建 |
| 调试破坏存档契约 | 只读检查、合法路线、调试/正式数据隔离 | 不发布任意状态注入接口 |
| 发行物泄漏私有文件 | 纯内容根、发行清单、源码外验证 | 泄漏扫描失败阻断交付 |
