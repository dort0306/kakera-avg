## 限制与未验收项

- Live2D 验收为 Haru 一个真实样例。CPU 合成最长边 512、约 30Hz；未量化复杂模型、多实例、高 DPI/不同显卡性能，不代表支持所有 Cubism 功能。
- 无 physics3 求解、完整 Pose 渐变/动作混合、自动口型/跟随、模型动作声音与新版 offscreen/高级混合；辅助资源读取不等于相关功能已实现。
- 实际窗口验证了片头自然结束、片尾提前跳过与菜单暂停。不可跳过视频、错误目标回滚等边界主要由严格解析/纯计划测试及代码提交边界覆盖，未逐个做 GUI 故障注入。
- 自动保存写失败/坏档/原子替换失败通过文件测试验证，未在 GUI 人为破坏用户数据目录。变量变化与三种结尾、裁剪历史检查点由完整回归验证；本轮跨进程 GUI 使用 question 初始变量槽。
- Windows 系统媒体组件必须可用；其他系统/容器/编解码器未验收。视频不保证精确 seek/音画同步；读档从起点重播。
- 实际音频设备流已建立；主观听感、实际扬声器和多设备切换未验收。
- 默认便携包不包含 Core DLL 或 Haru；本地 SDK/模型许可原文保留在生成测试游戏中，未公开发布第三方素材。
