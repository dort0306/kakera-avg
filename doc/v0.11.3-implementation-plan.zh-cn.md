## 2. XML/JS 优先评估与范围

设置页布局、滑条、标签、事件和组合控件均复用现有 XML/JS，不新增 Rust 控件或脚本音频对象。总音量不能只靠既有 API 无损实现：把四个通道都改写成乘积会丢失原有分项值，UI 瞬时变量也不能作为可靠的跨进程偏好存储。Rust 需要最小扩展设置字段、绑定白名单、命令校验和播放增益计算。

本版目标为保留现有分项能力，增加 master_volume，覆盖背景音乐、语音、剧情音效、UI 音效及 UI sequence 视频音轨。暂不增加 UI 音效单独滑条、角色专属音量、混音总线、淡入淡出、分贝曲线或任意脚本播放接口。

## 3. 拟议契约

- master_volume 为有限 number，0–1，默认 1.0；有效增益 = muted ? 0 : master_volume × channel_volume。UI 音效使用 se_volume，视频使用 video_volume。
- 总音量改变不重写任何分项值。master=0 保留分项与 muted；取消静音后恢复当前 master 与分项的乘积。
- 调节正在播放的 Sink，只更新增益，不重建、不重播、不改变进度或暂停条件。新建 Sink 在首次播放前应用已提交设置，防止瞬时全音量。
- 通过既有 ctx.setting 与 settings.* 绑定接入，沿用整批校验和 Settings 单文件原子写入；任何命令/候选错误或写入失败均保留旧 UI、偏好及实际声音，不提前改变音量。活动隐藏交接仍禁止设置持久 IO。
- settings.json 新字段必需，继续拒绝未知字段与缺字段，不使用 serde(default) 或自动迁移。旧设置缺 master_volume 时沿用当前“提示并采用完整默认设置”的规则，需在发行说明明确会重置偏好；只在用户之后成功保存时写出新格式，不主动删除旧文件。
- story 8/UI 3/save 9/profile 1/read 1/隐藏交接槽 1/KPAK 1、2/demo content-version=11 保持不变；新增绑定白名单不等于 schema 升级。设置与播放句柄均不入剧情 Model/存档。

1. 按 [专项交接](audio-volume-handoff.zh-cn.md) 扩展 Settings、命令及绑定；确定所有音频入口的统一增益计算。

3. 用 XML/JS 增加总音量滑条，保留四项分量与总静音；重排设置页，避免当前面板底部溢出。
4. 更新 API 已实现部分、README/PLAN、设置格式说明、发布指南和验收；功能完成前不把拟议 API 写成可用。
