# JS 注册 API 重设计验收方案

这是 v0.11.0 历史验收设计。v0.11.1 的独立事件、可空控件与单参数绑定按 [新方案](v0.11.1-implementation-plan.zh-cn.md) 和 [本轮验收](v0.11.1-validation.zh-cn.md) 执行。

日期：2026-10-31。状态：**已执行**，实际结果见 [验收记录](js-api-redesign-validation.zh-cn.md)。对应 [落地方案](js-api-redesign-implementation-plan.zh-cn.md)；本文件保留为验收设计与用例清单，不预填通过结果。

## 1. 验收原则与准备

基线：story 8/UI 3/save 9/profile 1/read 1/隐藏槽 schema 1/KPAK 1、2，demo content-version=11。新入口为 frame(id).advance/choice/end 与 ui(id).bind(event, callback)；配套生命周期、虚拟目标和事件名规则以落地方案第 2–3 节为准。ctx 参数、快照与命令权限保持原样。

使用临时工程和独立 save-dir，不修改作者存档或既有发布目录。迁移前准备固定显式 ID 的测试工程、普通手动/自动槽和 active/inactive 隐藏槽，记录位置、变量、历史、generation、栈和序列。迁移同一份内容后由新实现完整加载；这些是验证语义等价的输入，不是在新版安装旧注册器。历史示例不计入当前正向用例。

优先扩展现有 script/UI/App/生命周期/包测试，新增专项集成测试可用 `tests/js_api_redesign.rs`。用真实 ScriptLogic、Controller、host::prepare 和 App 提交链验证，不以手工拼 manifest 或只测字符串替换代替。

## 2. 注册、路由与隔离

| 编号 | 输入/操作 | 必须得到的结果 |
| --- | --- | --- |
| R01 | 新语法覆盖 advance、多个 choice 的字符串/函数目标、可选 when、end；回调沿用原参数 | 注册成功，路由/变量/目标与迁移前等价；end() 不退出进程 |
| R02 | ID、name、跨章节目标、自循环、同一选择器多次 choice、跨 JS 文件辅助函数 | 严格解析到实际幕；自循环正常 entered，不因 ID 相同漏生命周期 |
| R03 | 同幕重复 advance/end、混合路由、重复 option、ID 与 name 注册同幕 | 全部拒绝，显示注册位置；没有覆盖或默认分支 |
| R04 | 缺幕、未知幕、choice 与 XML 不一致、空/非字符串 ID、targetOrRun 既非原始字符串也非函数、when 非函数 | 加载失败，保留 JS 文件/栈及相关 XML 位置；生命周期不补足漏路由 |
| R05 | 条件组合、首命中/兜底分支、隐藏选择伪造、无效 choice、坏返回值/目标 | 保持原条件逻辑；隐藏/非法选择失败，不跳默认项、不改 Session |
| R06 | set/add 类型、整数边界/溢出、越界、条件写变量、回调抛错 | 原子拒绝；位置/变量/历史/音频/效果保持原值 |
| R07 | 修改 frame/ui 全局函数、选择器方法；解构方法后调用 | 全局/方法不可覆盖；解构方法仍指向原目标，注册查重有效 |
| R08 | 回调用已保存选择器再次注册；通过闭包计数跨求值影响后续 guard | 封存后拒绝注册；每次隔离，无跨回调状态泄漏 |
| R09 | 无限循环、递归、堆耗尽、过量更新/命令、异步任务、Date/Math.random/IO 尝试 | 原资源预算和禁用能力继续生效；失败不提交 |
| R10 | 仅调用 frame(id) 未声明路由、重复构造同目标选择器 | 选择器不自动注册路由；重复构造不等于重复回调，按实际注册检测 |
| R11 | 对相同 advance/choice 分别使用 'target' 与 () => 'target'；choice 分别带/不带 when；包含跨章、别名和自循环 | 可选项、目标、变量、generation、历史、生命周期次数及存读档重放等价；静态目标不产生额外更新或提前进入 |
| R12 | 字符串目标未知/空；数字、bool、null、undefined、数组、对象、new String('target')；函数返回这些值或 Promise | 注册参数类型错误立即拒绝；未知静态目标加载时拒绝并定位到相应 advance/choice 调用；动态坏目标/返回值在执行时拒绝；不做字符串强制转换 |
| R13 | choice('id', 'target', when) 的条件为 false/抛错/尝试写变量；伪造隐藏选项；静态目标的进入候选失败 | 与函数目标走相同只读条件及事务校验；失败保留原 Session/UI/音频/历史，不因静态目标绕过校验 |
| R14 | 声明函数目标但不触发路由；仅将静态目标改成等价函数后热更/打包/加载旧槽 | 注册不执行目标函数；manifest 能区分静态与动态且保留各 choice 位置；语义等价时内容版本不变、历史仍可完整重放 |

## 3. UI 目标、XML 对照与事件派发

| 编号 | 输入/操作 | 必须得到的结果 |
| --- | --- | --- |
| U01 | button、slider、toggle、color-picker 使用原 event 名，绑定各自 ID | 单次派发；ctx.item/value 类型与旧接口相同，业务命令结果相同 |
| U02 | 两个按钮 event 相同、callback 不同；共享 callback 绑定多个具体目标 | 各执行自身回调；同名不串台；复用函数不产生广播 |
| U03 | 同一目标/事件跨文件重复绑定、未知目标、错大小写、漏绑定、多余错事件绑定 | 完整装配后拒绝，给出首次/重复 JS 位置或 JS/XML 对照位置 |
| U04 | event='advance' 却 bind('click')；XML 无 event 只写 bind('click') | 拒绝；不隐式生成 DOM 事件或全局回退 |
| U05 | label/image 等非交互节点绑定普通事件；route 按钮绑定 JS | 拒绝；route 继续走原 Open/Close 纯事务，不执行 JS |
| U06 | screen 背景左右事件、两属性同名/不同名、非顶层/控件遮挡/禁用/滚动/黑边/失焦 | 按 screen ID 精确派发；同名注册一次；沿用所有背景输入阻挡和一次更新一个意图 |
| U07 | repeat 的 choice/槽位/画廊多行点击、换页、滚动 | 使用模板控件 ID，ctx.item 对应真实点击行，不按第一项或上次行路由 |
| U08 | 试图绑定 repeat 运行期实例 ID、跨页面重复节点 ID、screen/节点同 ID、XML 使用 $game/$host | 严格拒绝歧义/未知/保留目标，不按找到的第一个节点执行 |
| U09 | 跨 include 文件的前向 UI 目标与事件引用、坏子文件与修复 | 完整装配成功后可引用；错误显示原子文件行列，修复可恢复 |
| U10 | 目标/事件含冒号等现有合法字符，构造不同 tuple 但拼接文本相同的注册 | 不发生键碰撞或误触发；不得为简化拼接随意缩窄原 ID 规则 |
| U11 | 真实 egui/宿主输入产生事件，经 App→JS→prepare→提交 | 来源 ID 和类别贯穿；不能只通过直接调用 logic.ui_event 的用例证明 |
| U12 | 热更后相同 event 改绑定控件、旧页面事件或旧捕获结果到达 | 旧事件不能误派到新目标；按候选定义/原清理规则拒绝过期来源 |

U01 的选色器须实际覆盖“候选被接受→松开→下一帧绑定”，外部色块/HEX 与标记一致；不能以手工更新渲染快照代替业务回调。拒绝候选仍恢复已提交值。

## 4. 生命周期、虚拟目标与续接

| 编号 | 输入/操作 | 必须得到的结果 |
| --- | --- | --- |
| L01 | frame.enter/exit 与 screen.open/close 新语法，首幕、普通推进、自循环 | 执行次序与当前 App 相同；Controller 完整验证先于 exit/enter；每次该执行时只执行一次 |
| L02 | frame.enter/exit 尝试 ctx.set/add；screen 生命周期尝试 ctx.quit/持久偏好；game.enter 原白名单 | 不因新目标类型扩权；原有允许/禁止矩阵逐项保持 |
| L03 | 正常/自动/快进/末幕补全与手动继续 | 补全不退出；末幕手动成功退出最多一次；Ctrl/自动仍停在结尾；失败可重试 |
| L04 | 新语法离幕交 UI，视频自然结束/跳过，screen.close 无参 resume | 正常路由更新只提交一次，跳过不穿透，返回正确 continuation |
| L05 | 同幕进入后交 UI、续接同幕、显式其他目标、不同显式目标冲突 | 同幕不重放 enter/exit；其他目标按原规则生成 resume_to；冲突拒绝 |
| L06 | 页面关闭顶层向下、打开下层向上、回调继续改栈、循环/32 命令/16 次派发 | 次序和预算保持；循环整批拒绝，不部分切页/播放/写文件 |
| L07 | ui('$game').bind('game.enter')，读槽/历史重放/CG 解锁/转场 | 仍按原调用时机、白名单和回放规则；不重复解锁写入或重播瞬时动作 |
| L08 | screen.open/close 绑定节点或虚拟目标；普通事件冒充保留生命周期；重复生命周期/别名重复 | 加载或受信任派发边界拒绝，普通事件字符串不决定权限 |
| L09 | captureShortcut(action, resultEvent) 原样调用，$host 注册结果 | 捕获成功使用原 ctx.item/value；取消/失焦/页切/释放屏障和权限不变 |
| L10 | 捕获结果只绑定在按钮、$host 缺结果注册、$host 使用保留名、虚构第三个虚拟目标 | 拒绝；不搜索所有控件，不回退到旧全局注册表 |
| L11 | 尚未开始时启动、热更、渲染重建；首次选择两个起始幕、普通载入 | 不自动运行默认幕；显式选择建立初始变量/单条历史，生命周期与音频各一次 |
| L12 | 隐藏槽坏文件、未知目标、原子覆盖失败、断点暂停及继续 | 保留旧 Session/UI/标题/声音/效果/隐藏文件；断点候选继续才写入并提交一次 |

## 5. 存档、热更和资源包

1. **固定 ID 等价迁移：**读取迁移前普通手动槽/自动槽，核对当前位置、所有变量、可用选项、history/resume_to、检查点与 generation。覆盖超过 1000 条裁剪重放、分支、自循环和显式 UI 返回；加载不会触发生命周期或新增自动槽。篡改变量/隐藏选项历史/错误返回边仍拒绝。
2. **隐藏续接：**迁移前 active 槽跨进程恢复只重开页面生命周期，视频从零；同幕/异幕返回正确，成功写 inactive。inactive 不在启动时自动进入，显式 resume 继续验证 continuation；末幕 source=continuation 仍要求完整状态相等及 End 路由。两个 schema 不能因 API 改造增加字段或默补。
3. **不兼容条件：**story/UI/save 旧 schema 继续拒绝；脚本旧入口拒绝；若内容语义发生改变，提升 content-version 后旧槽拒绝且文件不变。不把 KPAK 1 兼容解释为旧脚本兼容。
4. **真实热更：**隔离工程中修改新回调、原子保存/重命名、注入旧 on 或错目标、修复。失败保留旧 Session/UI/声音/效果，成功保留进度、不写自动槽/CG、不重播瞬时动作；过期候选丢弃。活动 sequence/隐藏交接/调试候选期间继续按原规则延后。
5. **两种包：**用真实 kakera-pack CLI 分别 --format 1/2 打包迁移后的 demo 和带别名/多入口/拆分 UI 的专项工程。独立重载并扫描全部块；包内 JS 保持作者原字节，不执行转译。UI 合并不丢 target ID/event，UUID 名字路由仍可解析；源 XML/JS 字节不变，固定 ID 的确定性保持。
6. **源码外发布：**两个包分别置于源码外干净目录，只带播放器、固定宿主 Core、包及必要许可，使用 --package ... --check；没有散装资源回退。旧脚本包或坏包必须失败；重打包/源变化/原子替换失败保留原输出。

## 6. 必跑命令与文档审计

在最终源码完成后执行并保留退出码与日志：

```powershell
cargo fmt --check
cargo clippy --locked --all-targets -- -D warnings
cargo test --locked
cargo run --locked -- --check
git diff --check
```

另执行实际两格式 CLI 与源码外 --check，参数按 `cargo run --locked --bin kakera-pack -- --help` 的现行帮助填写，不能只运行低层容器 API 测试。正式发布脚本本地验证不得公开上传或覆盖旧目录。SDK/大包等 ignored 用例按相关变化决定是否显式运行，并明确列为通过/未运行；不将 ignored 计为通过。

审计 `on.`、旧 UI 字符串集合与 name-only 派发路径：当前生产入口、demo、src 内嵌测试、tests、现行示例、生成脚本、README/API/指南/编辑器当前接口说明均完成迁移。旧入口出现仅允许在历史文档/示例和明确断言拒绝的负面测试中。源码里的合法业务变量名 on 或普通文字不作机械删除。

增加旧 on.advance/choice/end/ui/frameEnter/frameExit/screenOpen/screenClose 的明确拒绝用例，分别覆盖单独使用与混用新入口；不能只检查 `typeof on` 就算完成兼容清理。拒绝诊断有作者 JS 文件和栈，不要求另装会工作的旧入口来提供提示。

正式 API 手册须给出最小完整 XML/JS 配对、共享函数、repeat、背景输入、四生命周期、game.enter、捕获结果和 ctx 不变说明；区分数据 bind 属性和回调 bind 方法。旧公开手册可归档，历史原文不改写。同步 README 启动、数据契约与限制，但不能宣称本轮没有实际验证的能力。

## 7. 真实窗口与跨进程验收

使用默认 D3D11 和 CPU 各走一次核心链，独立 save-dir；不得仅用 --check 或离屏图证明 GUI 已通过。

| 场景 | 人工操作与应观察结果 |
| --- | --- |
| 起始与普通剧情 | 启动只显示 initial UI；选择两个入口分别只进入一次；中文/16:9/稳定换行正常；继续依次跳转场、补全、推进，选项不被背景点击或快进默认选择 |
| 同名事件隔离 | 两个真实按钮使用同 event、不同业务；分别点击，仅对应处理器生效；共享 close 函数在两个页面均正常 |
| 控件与 repeat | 选择选项、点击不同槽位/CG 行、拖滑条、toggle、HSL 选色后松开；ctx.item/value 对应当前控件和条目，不串台、不回跳 |
| 页面与输入阻挡 | route 打开/关闭页、JS 切页、背景左右键、禁用与滚动遮挡、菜单暂停；顶层交互且一次输入只有一个结果 |
| 捕获与偏好 | 捕获/取消/应用快捷键，确认 $host 结果更新正确草稿；配色/设置/语言页原事务生效，跨进程偏好保持 |
| 末幕/视频 | 末幕手动触发一次退出，补全/Ctrl/自动不退出；UI 视频自然结束及跳过分别单次 screen.close/resume，跳过不穿透；失焦/提示/调试仍冻结 |
| 热更 | 正常编辑可见效果，坏目标或旧 API 保留旧画面/位置/变量；修复后继续；不额外触发 game.enter/自动保存 |
| 跨进程槽位 | 保存末页第 200 槽及自动槽，完全退出再启动，检查变量、选项、历史、截图/预览与位置；读档不写回自动槽 |
| 跨进程隐藏槽 | 视频中正常退出，重启从零播放；返回一次后再重启不自动重复；普通槽列表不出现隐藏槽 |
| 确认退出 | 取消保留剧情，确认走正常 shutdown；不触发 frame.exit/screen.close、不消耗 active 槽，退出补写仍执行 |

记录实际播放器构建、后端、操作、可见结果、日志/截图位置。实际音频设备流与主观听感分别报告：未听到/未使用音频不能写“声音正常”。本轮以回调派发回归为主，无关的全平台、多显卡、全 DPI 或大型媒体压力测试可单列未执行，不援引旧记录当本轮复验。
