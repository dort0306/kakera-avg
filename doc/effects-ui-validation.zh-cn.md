## 自动验证

新增 7 项效果测试，完整回归共 74 项：

- 全部转场的首尾、中点、方向/裁剪/透明度范围；黑/白幕中点覆盖；缓动单调性。
- 全部图片动画结束回基准、零时长、暂停时间不增长、跳过、读档最终态、自循环重新进入。
- RGBA 灰度/棕褐/模糊/像素化及透明度；预乘 alpha 模糊不会从全透明隐藏颜色产生色晕。
- XML 未知类型/引用、非法数值/组合/颜色/布尔值/重复 ID，诊断保留文件位置。
- JS 生命周期权限、非法/重复转场、repeat/未知目标拒绝，以及局部 UI 赋值与效果命令整批回滚。
- 实际 egui 绘制读取预生成纹理，滑动场景按固定区域裁剪，不在绘制执行 JS。

旧 XML、JS 剧情、变量、历史检查点、六槽/旧档/原子替换和无设备音频测试继续通过。`cargo fmt --check`、`cargo clippy --locked --offline --all-targets -- -D warnings`、`cargo test --locked --offline`（74 项）、`cargo run --locked --offline -- --check` 和 release 构建均通过。首次进入区分“没有旧画面”以及新增跳过文案字形检查后，另外复跑 effects 七项和 assets 三项均通过。Windows 增量缓存偶有硬链接回退复制提示，未产生 Clippy 诊断错误。

## 实际窗口观察

使用 `--save-dir target/gui-effects-v05 --no-audio`，隔离目录首次创建，不访问既有用户存档。文字速度 2，静音，正常 1280×720 客户区。

- “效果演示”页正常打开，中文清晰，灰度、棕褐、模糊、像素化四种预览有对应外观；未见溢出诊断。
- 点击缩放与闪白，观察到图片尺寸/白色覆盖的中间态；效果限制在预览图片区域，控件未随图片移动。
- 白幕转场中观察到接近全白的场景，HUD 按钮、对话框仍保持正常颜色与位置，台词未开始显示，按钮文字为“跳过转场”。
- 演示时长可调到接近 5000ms；“暂停预览”将转场与历史菜单一同启动，菜单停留超过总时长后仍显示活动转场，逐字未积累。该演示页 pause=false，普通菜单 pause=true。

- 在暂停菜单停留后点击“跳过转场”，仅关闭过渡，台词显示单字“午”，仍为 opening；下一次空格补全 opening，再下一次才进入 question，转场中选项保持隐藏。
- question 写入新的槽 1，完全退出（exit 0）后启动新进程，从 XML 读档页读取；立绘立即以最终透明度显示、整句台词与两个可用选项直接恢复，没有重播其 dissolve 或 portrait.enter。JSON 继续 schema 3 / content_version 3，未写入动画字段。
- 历史窗口确认 trust=0、met=false、invited=false、mood=平静，两条 opening/question 与 JSON 一致。效果页最大化至 2048×1104 截图时保持 16:9 居中留边，过滤预览及控件等比放大。
- 最大化时实际观察向左滑动：旧场景/立绘向左离开，新背景从右进入，游戏区域外留边保持黑色，HUD 与对话框未随场景移动。验收进程均正常退出。

便携包位于 `target/package/kakera-avg-v0.5`，从 `D:/codes` 工作目录运行包内 exe `--check` 通过（7 场景、4 剧情变量、3 JS、9 UI 页）。包内 exe 与最终 release 哈希一致，包含 UI/JS/图片/字体/许可及更新后的 API、策略和验收文档；运行内容目录无旧 flow.xml、开发槽位、设置或 CG 进度。

## 限制

本轮 --no-audio，不新增听感或设备热拔插结论。其他操作系统、DPI/多显示器、长期运行和所有作者布局未验收。全部方向/动画首尾由数学测试覆盖，实际窗口只报告已观察的代表效果。dissolve 为分层纹理混合，非离屏整场景后处理；无自定义 shader、遮罩资源、任意关键帧或无限循环。过滤缓存有 256MiB 上限，但不把测试通过解释为任意大素材组合的性能保证。
