# 工作包 A：动态图片与 CG 查看验收方案

版本归属：**v0.10.0**（2026-10-30 定稿）。本文是验收任务清单，不是逐项通过记录；实际执行结果、修复复验及仍未完成的环境矩阵见 [验收记录](ui-extensibility-validation.zh-cn.md) 与 [独立复验](ui-extensibility-independent-review.zh-cn.md)，不得因版本定稿将未验项目改记通过。

## 1. 固定用例与记录

使用临时工程/独立 save-dir，准备三张可辨认的合法已声明图片：16:9 横图、竖图、正方形；一张有透明区，一张专用 CG。另设普通 image、未解锁收藏、非法音频引用、尺寸不同的图集。图片使用有权测试的素材，保留许可证，不改玩家数据。

记录查看页和 image 的固定 ID、初始图片 ID、变量/历史/profile 摘要与资源缓存计数。每条用例填执行版本、工程/包、渲染后端、步骤、实际结果、日志；未执行与失败不能写通过。

## 2. 自动测试清单

| 编号 | 场景 | 必须断言 |
| --- | --- | --- |
| A01 | UI string 初值及 JS 切换 | 同一 image-bind 从资源 A 到 B/C，最终绑定/标题正确 |
| A02 | 独立和共享绑定 | 共用变量的两个控件同步，独立变量不被误改；这不是纹理复制 |
| A03 | 绑定非法 | 未声明、空字符串、文件路径、URL、错误资源类型/变量类型拒绝；错误含原 UI 文件/位置或 JS 栈 |
| A04 | 整批回滚 | 改标题/图片并打开页面，图片或 region 最终非法时全部不提交；与 Save 等操作同批也不得先写文件 |
| A05 | fit 与尺寸 | 横/竖/方图 contain 无裁切/拉伸，cover/stretch 仅明确配置时生效；透明区按既有 alpha 合成 |
| A06 | 缓存 | 连续切换 100 次不逐次新增相同资源纹理，不重复解码；不把预先准备的滤镜副本当切图泄漏 |
| A07 | 图集组合 | 当前图像+region 最终边界校验，越界失败保留旧图；只改 UV 不重复上传 |
| A08 | 解锁 | JS 拒绝未解锁条目；禁用按钮无事件；查看不改 profile；不将此测试解释为加密防提取 |
| A09 | 页面栈 | 模态版关闭只回原画廊；单 image 的非模态根页不露旧内容、用显式事件返回，close 唯一根页仍拒绝；切图不重复 open |
| A10 | 工具栏与背景输入 | 顶层背景首次点击只恢复工具栏；按钮/滚动/黑边/失焦不触发背景切图，单次输入只有一个事件 |
| A11 | 剧情隔离 | 查看前后 frame_id、变量、history、自动档代数不变；不会执行 game.enter/frameEnter/Exit |
| A12 | include/包 | 子 UI 前向绑定和原位置诊断，KPAK 1/2 完整装配后同样可切图，源工程字节不变 |

若实现可选上一张/下一张，还必须覆盖：首尾禁用、仅一张解锁、稀疏解锁、同资源不同收藏 ID、稳定顺序、不绕过未解锁、重复点击同项，以及导航失败不先更新当前 ID。未做通用导航能力时，必须明确范围，不假造 ctx.gallery。

## 3. 实际 GUI

1. D3D11 工程窗口打开三张不同宽高比图片，确认每次还是同一查看页/同一控件；背景确实覆盖底层画廊，中文标题、contain 留边和 16:9 正常。
2. 隐藏工具栏，再点背景仅恢复工具栏；点返回只返回画廊，不推进/补全剧情，不改变已读/CG。
   另用仅含单个 image 的非模态根页复验：图像透明区/contain 留边为黑色而非上页残留，返回按明确作者路由恢复正确页面组合。
3. 在 CPU 像素模式复验切图和透明边，实际确认后端。连续查看/关闭/切换不闪旧图、不积累纹理；黑边不是有效点击区。
4. 分别从两种真实包运行相同操作，包外没有游戏散资源；只读包不回退目录。
5. 若测试系统全屏，单独记录窗口设置切换、非 16:9 显示器留边、关闭后的设置持久化；不能以这一步替代舞台内图片适配。

## 4. 性能与故障

用计数器/可复核日志证明读盘/解码/纹理安装发生在准备阶段，不在绘制。GPU readback 仅作测试像素比较，不能变成切图常规路径。注入坏候选图片/JS/绑定，旧图、旧 Session、音频与 profile 保留；修复后可继续切图。

## 5. 交付

执行总入口的全部检查、真实 CLI 两种包与以上 GUI，用新文件记录实际通过/失败/未执行。补充 image-bind 既有用法与限制，不宣称本轮新增了尚无必要的 Rust 图片加载 API。音频听感、全部 DPI/跨屏等若未测须列出。不得把本计划本身或过去版本测试总数当作本包验收。
