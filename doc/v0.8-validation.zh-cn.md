# v0.8 验收记录

日期：2026-10-25。依据 [落地策略](v0.8-implementation-plan.zh-cn.md)。本轮工作前已有 v0.7 系列未提交修改，本轮在当前工作区继续完成，没有提交或推送 Git，没有删除用户存档。

## 交付范围

- 应用版本 0.8.0；唯一现行契约 story 8 / UI 3 / save 8，demo content-version=8。KPAK 1、CG profile 1、read 1 各保留一个当前格式。
- Windows 客户区固定 16:9，默认 1280×720、最小 640×360 逻辑尺寸。WM_SIZING 约束八个边/角，WM_WINDOWPOSCHANGING 约束系统/程序尺寸；扣除原生边框，按 DPI 取物理 16×9 整数单位。
- 无边框全屏占当前显示器；关闭后恢复本次进入前的尺寸/位置。默认窗口化；独立 settings.fullscreen 跨进程保存。XML toggle + JS ctx.setting 复用现有设置事务；Rust 只补充窗口系统能力和 bool 白名单。
- AGENTS.md 已增加“新需求优先 XML/JS，现有宿主能力不足才扩展 Rust”的约定。

## 兼容代码清理

当前程序不运行旧 story 1–7、UI 1–2、save 1–7，不猜测或迁移旧文件。旧说明和示例仍保留在 doc；v0.7.3 README/API/指南另存 doc/archive。

删除了旧 flow XML 解析器、声明式条件/路由执行器、默认隐式 Logic 入口、旧档导入、无 XML UI 的原生兼容菜单和旧界面绘制路径。LoadedStory/PlayerApp 的 XML UI 为必需；运行资源统一走 ContentSource，删除绕过来源的重复目录加载接口。变量类型校验/更新计划仍保留为当前 QuickJS 提交边界，不属于旧规则执行器。

settings.json 必须完整包含当前字段；缺少 skip_all/fullscreen 等字段时报错并由 App 提示、采用完整默认值，不进行字段补齐。save 8 的 screenshot 字段必需，可显式为 null（无窗口工具快照），旧无字段格式不再接受。保留原子替换、资源预算、完整历史重放与失败回滚。

历史兼容专用测试已删除；脚本隔离、变量回滚、资源/历史/原子写入等仍有价值的测试和 fixture 已迁为当前 XML/JS 契约。旧输入仅用来测试明确拒绝，不保留旧格式正向执行测试。

## 实际窗口与持久化

使用 computer-use 技能操作本轮 debug D3D11、CPU 像素路径和本地 release 发布窗口，均使用 --no-audio。用户数据隔离在 target/v08-gui-saves。

- 初始外框截图 1282×751，客户区画面 1280×720，中文和按钮正常，画面无比例黑边。
- 通过原生系统菜单“大小”与鼠标定位实际缩小窗口，观察到外框 642×391 的最小窗口，以及 987×586 的中间尺寸（截图逻辑像素有 DPI 取整）。背景、台词和控件仍等比铺满客户区。八个方向的精确物理矩形由纯测试验证；直接拖角/各边的完整人工矩阵未完成，不把工具未命中边框当作成功。
- XML 设置页切换至 2048×1152 无边框全屏，关闭后外框恢复 1282×751，原窗口位置恢复；移动窗口后也完成模式切换。最小窗口同样能使用开关进入全屏。
- 全屏 true 写入 settings.json，完全退出后以 --renderer cpu 重启，直接恢复全屏；关闭后恢复默认窗口尺寸，再启动 release 仍为窗口化。设置页中文、开关和提示未溢出。
- 在 CPU 窗口执行一次“散步”选择，将 trust=1、met=true、mood=期待和三条历史保存至末页第 200 槽；文件为 save 8/content 8，截图为 320×180 PNG。完全退出后，独立 release 发布进程读取该槽，画面恢复 walk，历史页实际显示三条记录及上述变量；继续可回到相应条件选项。
- 末页第 200 槽显示保存时间、匹配缩略图和台词预览；手动与自动页预览未显示 frame ID。历史页保留自身的场景 ID 展示，这是历史功能，不属于槽位预览。
- 在 release 进程读取上一 CPU 进程生成的 auto-5，恢复 walk；读取前后所有 auto 文件 SHA-256 相同，没有读档写回。
- release 从程序旁 game.kpak 和 Core 运行，无工程浮窗、无随播放器出现的控制台，目录无游戏散资源。测试窗口均正常关闭。

## 发布与未覆盖项

本地发布目录为 target/package/kakera-avg-v0.8，仅用于本地验证，未公开上传。随包保留字体、Haru、Core 与依赖许可；不分发用户数据或游戏散文件。当前手册、指南、示例和本验收同步随包。最终副本另复制至源码目录外的系统临时目录，程序旁发现 game.kpak 后 --check 退出码为 0；目录记录于 target/v08-external-package-path.txt。

非 16:9 显示器全屏仍等比留边，这是避免拉伸/裁切 UI 的设计；本轮实际显示器为 16:9，没有实查其他比例、多显示器跨 DPI、系统贴靠的全部组合、驱动真实丢失或其他平台。直接鼠标拖动八方向的完整人工矩阵仍待补查。

本轮完成媒体解码、真实 Cubism SDK 与 GPU/CPU 自动回归，没有重新走完所有视频首帧/音轨/菜单/结束/跳过、模型动作、持续按住 Ctrl 组合和真实热更新 GUI 矩阵。GUI 使用 --no-audio，未验收实际音频设备流与主观听感；历史版本记录不当作本轮复测结果。
