## 1. 交付范围

- 宿主接入 fluent-bundle/fluent-syntax/unic-langid，正式目录只有 zh-CN。内嵌资源 1048 个消息；扫描 Rust/JS 的 1042 个字面量调用 ID，缺失 0。稳定 ID 追加维护，迁移索引见 engine-i18n-message-index.json。字体种子来自实际词条，保留 Fluent 方向隔离符。
- Model/Controller 使用拥有的 Diagnostic，不持有 Fluent、平台或 IO。领域错误在宿主边界格式化；作者消息和选项正文保持数据语义，不把相似诊断标记当作程序执行。
- 游戏国际化默认关闭；显式清单 schema 1，文本/语音独立匹配、默认值、回退、UI 命令和 language.json。剧情/UI/标题/历史/变量标签/画廊/槽位摘要接入缓存投影，语音只映射剧情 voice。
- 兼容译文热更保留可复用页面栈、UI 变量和当前槽页，不重放进入回调；不兼容 UI 定义继续按原有重建规则处理。音频候选替换不重播活动通道。
- 应用及发布脚本默认版本为 0.10.1；story 8/UI 3/save 9/profile 1/read 1/KPAK 1/2/demo content-version=11 保持原契约。新增偏好文件不入剧情档、包、显式附加或工程监控。

## 3. 新功能自动覆盖

- 宿主 FTL 语法、重复 ID、缺引用、循环、函数、深度、指数 DAG；空引用也计入展开和隔离开销。16 个短参数可以格式化，超限长参数在调用 Fluent 前拒绝；默认方向隔离、精确整数及完整参数契约生效。
- 字体种子按 Fluent 实际语义解码字符串中的 Unicode 转义；错误求解超限使用中文兜底，不把内部词条 ID 当作界面文案。
- 独立文本/语音集合，手动优先、有序系统命中、无命中默认、已移除请求保留且默认、空语音集合禁用、严格偏好字段/重复字段/大小写拼写/预算。
- 关闭时忽略未引用的坏清单/FTL，使用新增 key 时拒绝；坏默认值、坏引用/资源类型、动态 key/参数错误整批回滚。
- 非默认缺文本整条回退，非默认缺语音用默认映射，silent=true 不再回退，默认语音缺映射拒绝。
- 实际 PlayerApp 语言事务：同一 Session/history，文本变化完整显示并更新 revision，只改语音不改变画面 revision，相同 effective 不重置；启动重读偏好，坏文件字节保留，原子替换失败及 pending 截图阻挡均保留旧状态。
- 当前语言投影覆盖台词/人物/选项/历史选择、变量标签和数值、画廊标题、第 200 手动槽以及自动槽摘要。存档仍使用实际 frame ID，读档不恢复语言偏好。
- 两种容器的全语言依赖、UI include 合并、具名场景 UUID、源字节不改写及 language.json 排除。
- 译文热更回归：保持 hud 页面、UI 数值变量、Session/history，不回到初始菜单。

## 4. 真实 CLI 与源码外包

用 tools/prepare-localization-demo.ps1 生成隔离工程；原 games/demo 没有开启国际化。分别执行真正的 kakera-pack.exe，--format 1/2、--level 1、--no-live2d，生成 target/i18n-publish/example-v1.kpak 和 example-v2.kpak，两者均完整独立重载通过。

将 exe 与两包复制到全新的系统临时目录，只从该目录启动 --package ... --check --no-live2d；使用 Start-Process -Wait 核对进程退出码和“校验通过”完整输出，两个包均通过。未分发散装 FTL、字体、音频或源码目录；宿主提示来自内嵌资源。此项没有执行公开发布或上传。

热更复核使用独立 --project/--save-dir/--debug-listen/--debug-token-file，恢复初始调试暂停后从 UI 开始。调试接口只用于核对真实进程状态，没有 eval 或任意跳转。窗口截图捕获存在中间帧/焦点干扰，因此以稳定画面与同一进程状态交叉核对；不将单张中间截图当作完整验收证据。

本轮未重做所有 DPI/所有 200 槽实际点击、全部视频/隐藏交接的跨进程 GUI 矩阵、60 秒大目录内存压力或非 Windows GUI。既有自动测试通过不能替代这些专项实际验收。

## 6. 音频与限制

无设备测试已覆盖语音映射/缺失回退/显式静音。实际设备启动记录为双声道 48000Hz/F32 输出流成功建立；这只证明设备初始化，未逐项测量换语言时 Voice/BGM/SE 的实际设备时序，也未完成真人主观听感。示例的 zh-CN/ja-JP 是已有 WAV 的占位映射，不能称为正式中文/日语配音。

正式宿主仅中文。非 Windows 系统语言探测目前默认降级；不承诺 RTL/复杂塑形、逐语言图片/视频/模型、多音轨、剧情带外部参数或超原预算的语音流式播放。Fluent 属性/属性引用、带参数术语和自定义函数明确拒绝。现行完整接口见 API 第 36 节。
