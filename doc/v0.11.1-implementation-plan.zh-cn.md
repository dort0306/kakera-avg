# v0.11.1 独立事件与可选控件绑定落地方案

日期：2026-10-31。依据用户追加要求，在 v0.11.0 上拆开事件定义与目标绑定。实际结果见 [验收记录](v0.11.1-validation.zh-cn.md)，接口见 [API 第 37 节](xml-js-api.zh-cn.md#372-v0111-独立事件与可选控件绑定)。本文覆盖此前“回调必须选择目标”和“控件事件必填”的规则；旧验收保留为历史。

## 创作契约

```javascript
// 绑定和定义支持前向引用，事件可以尚未被任何控件使用。
ui('continueButton').bind('advance');
event.register('advance', ctx => ctx.advance());
ui('otherContinue').bind('advance');
event.register('unused', ctx => ctx.message('尚未绑定的事件'));
```

```xml
<button id="continueButton" width="120" height="40" text="继续" />
<button id="otherContinue" width="120" height="40" text="继续" />
<button id="draft" width="120" height="40" text="待配置" event="" />
```

- `event.register(id, callback)` 仅收集独立定义。ID 为非空原始字符串，callback 为同步函数，返回 undefined。重复 ID 拒绝，给出两处注册位置；不覆盖、不广播，无引用定义合法。
- `ui(id).bind(eventId)` 只有一个参数，仅收集绑定。完整 UI/JS 装配后验证目标和事件，支持跨文件前向引用。旧普通两参数 bind 不再接受。
- XML event 可直接引用函数，无需 JS bind；省略或空字符串均为未绑定。JS/XML 同时声明同一引用允许，冲突拒绝；重复 JS bind 拒绝。未知非空引用不能静默变成未绑定。
- 多控件共享一份定义；不同业务用不同 ID。repeat 绑定模板子控件，真实条目仍走 ctx.item/value，不新增 DOM/emit/eval。
- 未绑定控件不执行业务、不自动提交绑定值或文件，仍占据交互区域阻挡背景。route 与有效事件互斥，sound-only 保留，只读节点不能通过 bind 获得交互。
- screen 背景左右属性也可为空并分别引用事件；两者均无声明时 JS bind 挂左键，已有声明时只确认已有引用，不隐式覆盖右键。不同左右行为使用 XML 两属性。

## 生命周期与捕获结果

生命周期入口保持 `frame(id).enter/exit(fn)`、`ui(screen).bind('screen.open'/'screen.close', fn)`、`ui('$game').bind('game.enter', fn)`。它们是宿主类型化钩子，不是普通控件事件，顺序、权限、末幕退出、同幕续接、预算和隐藏槽事务不变。普通 event.register 禁止这些保留名和历史生命周期前缀。

`ctx.captureShortcut(action, resultEvent)` 参数不变，resultEvent 直接引用独立事件，不需要控件或 `$host` JS 绑定。旧 `$host` 两参数注册删除；宿主仍以 Host 类别执行普通 UI 权限，取消/失焦/页切/释放屏障不变。真实 XML 中 `$game/$host` 保留。

## 宿主改动与实施顺序

已有 XML/JS 无法拆开宿主注册表和控件必填校验，故最小修改桥接/装配/派发，不增加命令或 IO 权限。

1. 桥接：新增冻结的全局 event 与私有事件表，分离定义和绑定 manifest，携带作者位置；保留独立生命周期表。封存后不能注册/绑定，每次隔离求值，原内存/时间/堆栈/更新预算不变。
2. 装配：合并完整 XML/JS 后将有效 JS 引用写入拥有的 UI Definition，和 XML 引用统一校验。定义无需目标，不再反查“每个回调必须有 XML 控件”；有效引用必须有唯一定义，保留 include 原位置。
3. 派发：渲染只读有效绑定；ScriptLogic 保存装配后的允许派发键，同时检查来源与事件 ID，不能因全局函数表而允许未绑定控件伪造调用。Host 结果、生命周期保持明确类别，不按字符串授予权限。
4. 事务：复用原 ctx、Command、host::prepare 和 App 候选流程，32 条 UI 命令/16 次生命周期预算不变；无事件总线、常驻解释器、动态 UI 创建或异步 runtime。
5. 迁移：demo、测试、当前示例和生成器独立 register，共享函数只定义一次；demo 继续按钮展示无 XML event、通过 JS bind 连接。API 当前示例更新，原 v0.11.0 手册归档，旧方案附覆盖说明，不改写旧验收。
