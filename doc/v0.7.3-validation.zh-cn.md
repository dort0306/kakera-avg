## 实际窗口验收

全部使用调试构建、独立存档目录、`--no-audio`，硬件 D3D11（feature level b000）。通过窗口截图直接观察，未从测试推断 GUI。

### 快进（内置兼容界面，临时 schema 3 工程）

| 步骤 | 实际结果 |
| --- | --- |
| 等待开场句显示完整后按住 Ctrl 1.5s | 自动补全并推进过已读开场与已读第二句，停在**未读的长第三句**，该句以正常速度继续逐字显示；未跳到选项页。 |
| 检查 `read.json` | 内容为 `{"schema_version":1,"story_id":"skip-gui","frames":["opening","second","third"]}`，第三句显示完整后被记录。 |
| 打开设置窗口 | 出现新复选框「全部快进（关闭：只快进已读）」，默认未勾选；勾选并保存后 `settings.json` 含 `"skip_all": true`。 |
| 点「重新开始」后按住 Ctrl 2.5s | 全部模式下直接跨过未读长句到达选项页，显示「要选择吗？」与「接受 / 结束」，右下角「请选择」；持续按住未自动选择。 |
| 松开 Ctrl | 保持选项页，未继续推进。 |

## 未覆盖与边界

- 未在 GUI 上组合验证 Ctrl 与自动播放同时开启、Ctrl 遇到视频、以及非顶层页面下的 Ctrl（后者由 `blocked` 与失焦判定在代码与单测中覆盖）。
- 只读模式的「未读停住」在窗口里用兼容界面观察；XML UI 走同一 App 路径，未另做该场景的窗口截图。
- 本轮不改存档格式，未重跑第 200 槽、跨进程读档与热更新窗口（上一版已验收）；`read.json` 的坏文件、写失败与原子替换由自动测试覆盖。
- 实际音频设备与主观听感未验证（`--no-audio`）；多显卡、高 DPI、驱动设备丢失仍沿用既有未验收边界。
- 真实 Cubism 用例默认忽略，本轮未重新运行。
- `skip_all` 属新增设置字段：旧 settings.json 缺字段时按 false 读取，首次保存后写出；不支持更早版本的设置迁移。
