# 可配置窗口标题策略

日期：2026-10-26，v0.8.2 后续功能；应用版本及 story 8/UI 3/save 8、KPAK 1/2 不变。

已有 XML/JS 只能配置游戏内标签，不能修改宿主原生窗口标题，因此需要增加这一处宿主窗口能力。交互继续复用 ctx.setUi，不新增脚本窗口句柄、IO 或命令。

- UI 根节点接受 title（静态文字）或 title-bind="ui.xxx"（UI string 变量），二者互斥；缺省标题为 Kakera AVG。初始配置与绑定必须严格校验，错误保留 XML 文件位置。
- 标题非空且非纯空白，最多 256 个 Unicode 字符，不含控制字符。JS 使用现有 ctx.setUi 修改绑定变量；整批命令结束后校验最终值，失败不改变旧标题、UI 或剧情/IO 状态。
- UI State 缓存已校验标题；宿主在 App 提交后的更新边界同步，仅值改变时调用原生窗口 API。启动窗口采用配置初值，进入事件可在首次显示前更新标题；不附加引擎/后端后缀。
- 标题为瞬时 UI 状态，不进入 settings 或剧情槽；重启/热更重建初值；读档和重开沿用当前 UI 变量，game.enter 可按进入的场景重新赋值。坏候选不提交标题。
- 验证默认/静态/绑定、中文与特殊字符、坏类型/绑定/超长/控制字符、JS 整批失败回滚、进入事件和 KPAK 1/2；执行 fmt、Clippy、完整测试、demo --check，实际窗口验证启动与 JS 更改。同步 API、README、demo 和验收记录，未测项目单列。
