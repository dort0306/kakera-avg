# v0.8 窗口模式与单一数据契约

制定日期：2026-10-25，先于本版功能代码。用户要求固定窗口缩放比例、全屏/窗口切换，并从本版起移除旧版本兼容代码、优先 XML/JS 创作。

## 契约与清理

- 应用版本 0.8.0，新基线 story 8 / UI 3 / save 8，demo content-version=8；KPAK 1、profile 1、read 1 保持唯一现行格式。
- 只保留当前 story 单/多文件显式 next 链、外部 QuickJS 和必需 XML UI。删除 story 1–7、UI 1–2 的分支、flow 解析/声明式路由、无 XML UI 的内置菜单、旧档导入、默认逻辑执行器及旧字段补齐。
- settings.json 必须完整包含当前字段，新增 fullscreen=false；旧字段缺失的文件明确提示并使用默认设置，不自动迁移。save 8 的 screenshot 为必需字段，可为 null（无窗口工具快照），不猜测旧无字段存档。
- 原文档和旧数据示例仅保留为历史说明。通用边界/安全/事务测试迁到新 XML/JS；删除纯历史兼容测试，不保留另一套运行实现。

## 窗口与创作策略

- 新需求先判断能否通过现有 XML/JS 组合实现；只有缺少受约束宿主能力时扩展 Rust，此约定写入 AGENTS.md。
- 设置页的全屏开关用 XML toggle + JS ctx.setting("fullscreen", boolean)；持久化和整批原子校验沿用设置通道。Rust 负责真正的窗口系统调用；不向脚本开放原生窗口句柄。
- Windows 客户区保持 16:9，默认 1280×720、最小 640×360。原生 WM_SIZING 在拖动各边/角时修正外框矩形，扣除标题栏/边框；DPI、程序调整和系统布局导致的尺寸变化也校正。尺寸计算可独立测试，不在绘制中调整窗口。
- 无边框全屏占当前显示器；关闭全屏恢复进入前的客户区尺寸和位置。启动按独立设置恢复全屏。窗口化不提供破坏比例的最大化/贴靠布局；非 16:9 显示器全屏仍等比呈现并留边，不拉伸/裁掉 UI。

## 验证与交付

- 纯尺寸用例覆盖八个拖动方向、边框、最小尺寸、整数取整与恢复；真实窗口验证拖边、拖角、全屏切换与恢复位置/比例，中文、设置和输入不回归。
- 验证当前内容/槽位往返与严格旧版本拒绝、设置类型和事务失败、脚本隔离/预算、条件/隐藏选项/变量回滚/历史裁剪、截图/媒体/热更/打包回归。
- fmt、Clippy all-targets/-D warnings、完整 locked 测试、demo --check、独立包检查；实际 GUI/音频和未覆盖项分别记录。更新 README/API/指南/发布脚本/验收，保留 v0.7.3 文档归档，不提交或推送 Git。
