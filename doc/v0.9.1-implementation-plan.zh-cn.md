# v0.9.1 末幕退出修复

末幕 on.end 无后续场景，原实现仅在 entered 时执行 frameExit，导致末幕无法退出。现有 XML/JS 无法修复此宿主派发遗漏，需要修改 App 生命周期边界。

文字完成后的手动继续触发末幕 frameExit，每次进入最多成功执行一次；补全不触发，自动播放和 Ctrl 仍在结尾停止。无退出回调的末幕保持结束显示。普通读档/重开重新建立本次进入状态。

UI 交接保持 source=continuation，以 exited=true/entered=false 标识已经退出的末幕。加载时要求完整重放相同状态且路由为 End；返回同幕不重放进入/退出，显式返回其他幕仍正常进入。准备与原子写成功后提交，失败保留旧状态且允许重试。隐藏槽 schema 1、story 8/UI 3/save 9、content-version 9 和 KPAK 1/2 不变。

验证覆盖末幕单次派发、跨进程重建、同幕返回、键盘/JS 入口和原子失败重试，并运行完整回归。GUI、设备流与听感另行记录。

UI 起始幕增量：复用 ctx.resume(frame?)，控件和自动 screenClose 走同一事务；优先读取完整隐藏槽 continuation，省略目标且无槽时报错。显式目标不得被关闭回调的空目标覆盖，冲突目标拒绝。准备/校验/原子写成功后同步实际起始幕并提交。布局与回调不新增语法，仅修正 Rust 隐藏持久状态读取和目标合并边界。
