# v0.7.3 Ctrl 快进与槽位预览去 ID 落地策略

制定日期：2026-10-25，先于本版功能代码。目标：① 按住 Ctrl 快进剧情，并可在设置中选择「只快进已读」或「全部快进」；② 存档/读档页的槽位信息不再显示内部 frame ID。story 7 / UI 2 / save 6 / KPAK 1 的既有契约不变，不新增存档槽字段。

## 1. 输入与快进语义

- 按住 `Ctrl` 即快进：App 更新阶段以固定步长（约 40ms/步）执行，每步至多一次剧情操作，保持「一次更新最多一个意图」。
- 每步按既有仲裁顺序：先跳过进行中的转场 → 再补全未完成的逐字 → 最后按控制器推进。因此 Ctrl 不会绕过转场/逐字规则，只是把等待压到最短。
- 停止条件：选项页与结束页不推进、不替玩家选择；视频播放期间不快进（跳过视频仍需显式按钮或继续键）；菜单、提示、失焦、自动保存等待中一律暂停；不改变 `on.*` 回调语义与历史记录。
- 与自动播放的关系：Ctrl 是显式输入，优先于自动播放；松开 Ctrl 后自动播放按原规则重新计时（`enter`/暂停重置等待），不会补算快进时间。
- 兼容界面（无 XML UI 的旧内容）同样支持 Ctrl 快进；它不新增界面元素。

## 2. 已读进度

- 定义：某 Frame 的**整句文字完整显示过一次**即为已读；读档后当前句立即完整显示，同样标记。逐字中、视频遮住对话框时不算。
- 持久化：新增独立用户文件 `read.json`（不与任何剧情槽绑定），结构为 `schema_version: 1`、`story_id`、`frames: string[]`。与 settings/profile 一致：同目录临时文件 + 平台原子替换；坏文件提示并使用空集合；未知 frame ID 保留但不参与故事校验（章节临时移除后恢复不会丢进度）。
- 写入时机：内存标记后按节流（约 3 秒）落盘，并在退出时再写一次；写失败只记录日志并保留脏标记重试，不阻塞剧情、不弹模态提示（辅助数据，失败不应打断阅读）。
- 边界：最多 100000 条、单 ID ≤ 256 字节；文件总量复用 2MiB 读取预算。`read.json` 不属于存档槽、不进入 KPAK、不参与工程监控热更、不被 `--check` 创建或读取。

## 3. 设置与界面

- `Settings` 增加 `skip_all: bool`，默认 `false`（只快进已读）。该字段带 `#[serde(default)]`：旧 `settings.json` 缺少字段时按 `false` 读取，首次保存后写出，避免升级即回退全部偏好。
- 校验与绑定：`host` 的 bool 设置分支接受 `skip_all`；`settings.skip_all` 加入 XML 绑定白名单（bool）。原生设置窗与 demo 的 XML 设置页都提供开关，文案说明「关闭 = 只快进已读」。
- demo 只改 UI/JS（`ui.xml`、`scripts/ui.js`），不改剧情、变量与路由，因此 content-version 保持 6，旧档仍可读。

## 4. 槽位预览去 ID

- 现状：手动槽 `data.rs` 把 `preview` 拼成 `frameId · 台词`，自动槽 `save.rs` 也拼 `frameId · 台词`，原生菜单另起一行显示 frame ID。作者与玩家都不需要内部场景 ID。
- 改为：槽位 `preview`/`excerpt` 只含台词与状态（空槽、损坏原因）文本；原生菜单只显示相对时间与预览文本。`frame_id` 仍保留在 `SlotState`/存档 JSON 中供校验与加载，只是不再展示或拼进预览。
- 存档格式不变：`save 6` 的文件结构、截图、时间、身份校验均不动，旧档继续可读。

## 5. 打包、监控与文档

- `package::excluded` 增加 `read.json`，使发布包与工程监控都把它当作宿主用户数据。
- 同步 API 手册新增「按住 Ctrl 快进与已读进度」一节，并更新设置表、持久化表、`slots` 预览说明与 §22.3 的 excerpt 定义；README 增加功能与用户文件说明；AGENTS 增加本版规则。
- 版本提升为 0.7.3；README/API/发布指南的 v0.7.2 版本先归档到 `doc/archive/`，`package.ps1` 默认输出目录改为 `kakera-avg-v0.7.3`。

## 6. 验证

- 自动：快进计时器的按下即步进/节流/松手复位；只读模式在未读帧停止、全部模式跨过未读；选项页与结束页不推进；已读在文字完成时记录、按节流与退出落盘；坏 `read.json` 提示并使用空集；`skip_all` 旧设置缺失字段默认 false、非法值拒绝；手动槽与自动槽 preview/excerpt 不含 frame ID、`save 6` 旧档仍可读。
- 手动：真实窗口按住 Ctrl 观察「跳转场 → 补全 → 推进」；只读模式在未读句停下、全部模式继续；选项页不被自动选择；Ctrl 与自动播放、菜单、视频的交互；存读档页不出现 frame ID；中文、16:9、跨进程读档不回归。
- 记录已验证与未验证项；音频设备、听感、多显卡、高 DPI 仍按既有边界报告。
