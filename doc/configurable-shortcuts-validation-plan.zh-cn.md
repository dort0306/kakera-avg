# 工作包 B：玩家快捷键验收方案

版本归属：**v0.10.0**（2026-10-30 定稿）。本文是验收任务清单，不是逐项通过记录；实际执行结果、修复复验及仍未完成的环境矩阵见 [验收记录](ui-extensibility-validation.zh-cn.md) 与 [独立复验](ui-extensibility-independent-review.zh-cn.md)，不得因版本定稿将未验项目改记通过。

## 1. 纯模型与格式

| 编号 | 输入 | 必须断言 |
| --- | --- | --- |
| B01 | 默认映射 | advance/skip_sequence=Space，fast_forward=Ctrl；固定 edge/hold 语义，不接受任意动作 |
| B02 | 规范化 | Ctrl+KeyK 等固定 token，修饰顺序规范化；未知、重复、超长、路径、空分隔、多段序列拒绝 |
| B03 | 物理键 | 中/英文布局、Shift 标点和 IME 不把字符文本当键位；左右 Ctrl 对同一逻辑修饰绑定等价 |
| B04 | 保留键 | Escape、Windows/Meta、Alt+F4、Alt+Tab、Ctrl+Alt 等按方案拒绝；系统关闭未被劫持 |
| B05 | 冲突 | 剧情动作同键冲突；Ctrl 按住与 Ctrl+KeyK 前进的前缀冲突；Space 前进/Space 演出跳过合法 |
| B06 | 整体候选 | 两个绑定在同批交换成功；任何一个非法则全部回滚；null 禁用仅该动作 |
| B07 | JSON | schema/story_id/字段/重复键/三动作完整性/16KiB/截断/非法组合严格拒绝；不补旧字段 |
| B08 | 缺失与坏文件 | 缺文件默认无警告；坏文件一次提示并保留字节；不主动写默认覆盖坏文件 |

覆盖全部支持 token 的保存/读取往返、大小写/别名策略及错误诊断；不能只测 Space 和 Ctrl。存储格式不依赖当前 egui/winit 枚举序号。

## 2. 捕获状态机

- 更改按钮启动捕获，启动点击和当帧残留键不成为新值；必须先全部释放再武装。
- 普通组合/纯 Ctrl 按住都在释放后确认一次；系统 repeat 和同帧多个 key event 不产生多个结果事件。
- Escape、UI 取消、失焦、换页、页面关闭、热更、普通读档/重开、再次捕获都取消旧候选；不得把旧结果送到新页面。
- resultEvent 未注册、使用生命周期事件名、动作未知、重复捕获、和其他 IO/剧情混合时整批失败。
- Ctrl/Space/Enter 在捕获期间不会快进、补全、推进、跳视频或激活底层按钮；捕获结束的键释放后才恢复普通输入。
- 鼠标清空绑定是显式动作；所有键盘动作禁用后，仍可用鼠标打开设置、取消及恢复默认。
- 一次最多一个活动捕获和一个待投递结果；关闭/热更清理内存，不泄漏回调或原始键盘数据。

## 3. App 仲裁与剧情回归

| 编号 | 场景 | 必须断言 |
| --- | --- | --- |
| B20 | 前进改为 Enter | 原 Space 不再前进；Enter 每次只做转场/补全/推进之一，系统连发不额外推进 |
| B21 | 快进改为 Tab 或指定组合 | 原 Ctrl 不再快进；新键约 40ms 一步，选项/末幕停止，绝不代选 |
| B22 | 只读/全部 | 未读一进入就停并正常逐字；skip_all 才允许越过；已读文件规则不变 |
| B23 | 自动档等待 | 按住快进可跨多个截图等待继续，不必每步松键；恢复不补算暂停时间 |
| B24 | 自动播放 | 按住快进优先；未读刚完成不让 auto 偷跑；松开后重新等待 auto_delay |
| B25 | 菜单/提示/调试/失焦 | 阻挡期间无剧情操作，恢复没有陈旧按下；覆盖修饰键按下后先失焦、在外部释放等情况 |
| B26 | UI sequence | 独立改跳过键后原键失效；允许跳过只结束一次，不可跳过保持；返回剧情无穿透 |
| B27 | 控件编辑 | 同键用于按钮确认、捕获、IME、HSV 键盘调色时，低层不推进/快进；同帧鼠标与键盘仍单意图 |
| B28 | 配置切换 | 正按住旧/新键时应用映射，均要释放重按；热更/读档不恢复按住状态 |
| B29 | 多起始幕 | 初始主菜单的快捷键不隐式进入默认幕；加载或显式选线后才允许剧情键 |

媒体测试须使用真实 MP4，覆盖自然结束和跳过后的释放屏障；不能用只调用 Controller 的测试替代 App 消费验证。

## 4. 持久化与故障

设置页捕获/修改草稿不写盘；应用成功后整个映射及 UI 一起生效。模拟目录不存在、目标锁定、临时写失败、原子替换失败、序列化超限；旧文件/映射/Session/页面都保留，草稿策略与文档一致。批量修改同文件允许，跨 settings/颜色/profile/普通槽/退出混写拒绝。

完全退出并重启恢复新键位；加载旧剧情槽、自动槽、重开及隐藏交接不回滚偏好。恢复默认也是一次完整原子写，不删旧文件。两个故事 ID/两个 save-dir 隔离。

在工程根放入 keybindings.json 和大小写变体，确认监控不触发、KPAK 1/2 不包含、显式发布 include 不能绕过；不是仅测试用户目录不在工程内的情况。

## 5. 实际 GUI 操作表

1. 默认键位先复测，打开 XML 设置页，分别更改前进、快进、演出跳过；提示、按键中文名称和保存按钮保持 16:9/中文可读。
2. 尝试冲突与保留组合，看到明确错误而其他映射不变。用鼠标清空三个键，再用鼠标恢复默认，证明没有输入死路。
3. 从 opening 推进到选项，测试补全/转场/一次按下、不替玩家选择；只读与全部模式各一次，自循环与末幕各一次。
4. 在有自动截图的窗口按住新快进键连续推进，菜单/失焦后检查释放屏障，松开后检查自动播放重新计时。
5. 真实 UI 视频使用新键跳过，确认没有推进返回幕；在快捷键捕获页按同键不跳过媒体或剧情。
6. 完全关闭，重启后读手动/自动槽，确认键位仍是玩家设置；坏偏好和原子失败至少一次 GUI 故障注入，使用测试目录。
7. D3D11/CPU 工程窗口、两种发布包分别核对，记录真实后端及平台；未测跨键盘布局、远程桌面或其他系统须明确。

## 6. 交付审计

跑总入口检查及真实两种打包、源码外 --check。搜索硬编码入口，保留系统/捕获取消键须逐条说明。API 标明拟定接口已经落地的最终名称、完整键表、偏好格式和限制。输出新验收记录，分开列自动、GUI、设备/听感和未执行；不以“编译通过”替代焦点/键盘/跨进程验收。
