# v0.8.4 按钮 UI 路由

日期：2026-10-28。保留当前 UI 拆分实现，story 8/UI 3/save 8、KPAK 1/2 不变。

现有 XML/JS 可用 event + ctx.open/close 完成页面导航；本次要求按钮直接声明路由，现有解析器没有该属性，需要最小 Rust 声明/派发扩展。复用既有页面栈事务，不新增跳转宿主权限。

- button 可选 route="open:页面ID" 或 route="close"，与 event 严格互斥，必须选择其一；其他控件仍使用 event。
- 合并完整 UI 后校验目标页面，支持跨 include 文件引用；路由使用类型化事件，不运行 JS 回调。
- open 按既有 modal 语义压栈或替换根页，close 关闭当前顶层页。重复模态、八层栈上限、关闭唯一根页等错误由既有 host::prepare 整批拒绝，状态保持。
- 保持顶层交互、禁用/隐藏阻挡和单次更新一个意图，Model/存档不变。现有带其他副作用的 JS 事件继续保留。
- demo 将简单设置打开/返回按钮改为 route；更新版本、API、README、指南、验收及发布脚本。验证严格属性/目标、跨文件、页面栈/失败回滚、真实渲染事件、两种包与完整回归；GUI/听感未验证范围单列。
